## 2. 기하 정식화

### 2.1 오스큘레이션과 곡률중심 거리 A

ISO 16281 A.2.1, 식 (A.3) — ISO p.20 (PDF p.26)

$$A = r_{i} + r_{e} - D_{w} \tag{A.3}$$

`A` 는 클리어런스가 0인 상태에서 내륜 홈 곡률중심과 외륜 홈 곡률중심 사이의 거리이며, **ACBB 전 계산의 기준 길이**다.

### 2.2 초기 접촉각

ISO 16281 식 (A.1) — ISO p.20 (PDF p.26)

$$\alpha_0 = \arccos\!\left(1 - \frac{G_{r\,op}}{2A}\right) \tag{A.1}$$

- `G_r op` 는 **직경 기준**(diametrically measured) 반경 운전 클리어런스다. 반경 기준값을 넣으면 α₀ 가 √2 배 규모로 틀린다.
- ACBB 는 통상 α₀ 를 직접 사양으로 받는다. 그 경우 (A.1) 을 역산하여 등가 `G_r op = 2A(1 − cos α₀)` 로 두면 내부 표현이 일관된다.

### 2.3 내륜 곡률중심 반경

ISO 16281 식 (A.4) — ISO p.20 (PDF p.26)

$$R_{i} = \frac{D_{pw}}{2} + \left(r_{i} - \frac{D_{w}}{2}\right)\cos\alpha_0 \tag{A.4}$$

미스얼라인먼트 `ψ` 가 전동체 j 위치에서 만드는 축방향 변위 `R_i sin ψ cos ϕ_j` 의 모멘트 팔이 된다.

### 2.4 보조 파라미터 γ 와 홈 곡률반경 기준값

ISO 16281 Clause 4:

$$\gamma = \frac{D_{w}\cos\alpha}{D_{pw}}$$

ISO 16281 Annex B.2 (ISO p.27 / PDF p.33) — DGBB·ACBB·분리형 볼베어링의 **참조 기하**:

$$r_{e} = 0{,}53\,D_{w} \tag{B.1}$$
$$r_{i} = 0{,}52\,D_{w} \tag{B.2}$$

> Annex B.1 명시: 이 값들은 **근사값**이며, 실제 제조사 설계는 다를 수 있다. **실측/실제 기하 사용이 우선**이다. B.1/B.2 는 사양 미상일 때의 기본값(default)으로만 쓴다.
>
> ISO 281 §5.1.1 단서와 연결: `f_c` 표는 내륜 홈 ≤ 0,52 `D_w`, 외륜 홈 ≤ 0,53 `D_w` 를 전제한다. 그보다 **큰** 홈 반경을 쓰면 `f_c` 를 감소 보정해야 한다(ISO/TR 8646:1985 식 3–15).

### 2.5 점접촉 곡률합과 상대 곡률차

ISO 16281 Annex E, 식 (E.4)~(E.7) — ISO p.33 (PDF p.39). ISO 281 Annex B 식 (B.5)~(B.8) 과 **동일**.

$$\sum\rho_{i} = \frac{2}{D_{w}}\left(2 + \frac{\gamma}{1-\gamma} - \frac{D_{w}}{2r_{i}}\right) \tag{E.4}$$

$$\sum\rho_{e} = \frac{2}{D_{w}}\left(2 - \frac{\gamma}{1+\gamma} - \frac{D_{w}}{2r_{e}}\right) \tag{E.5}$$

$$F_{i}(\rho) = \frac{\dfrac{\gamma}{1-\gamma} + \dfrac{D_{w}}{2r_{i}}}{2 + \dfrac{\gamma}{1-\gamma} - \dfrac{D_{w}}{2r_{i}}} \tag{E.6}$$

$$F_{e}(\rho) = \frac{-\dfrac{\gamma}{1+\gamma} + \dfrac{D_{w}}{2r_{e}}}{2 - \dfrac{\gamma}{1+\gamma} - \dfrac{D_{w}}{2r_{e}}} \tag{E.7}$$

> 부호 주의: (E.7) 분자의 첫 항은 **음수** `−γ/(1+γ)` 이다. 외륜 접촉은 볼이 오목면에 닿으므로 곡률차 구조가 내륜과 다르다.
>
> 구현 주의: 이 네 식은 `γ` 를 통해 `α` 에 의존한다. ISO 는 여기서 **공칭 접촉각 α** 를 쓰지만, 하중하 운전 접촉각 `α_j` 가 크게 벗어나는 고하중 조건에서 `γ` 를 `α_j` 로 갱신할지는 ISO 가 규정하지 않는다 → §11 미해결 항목 T-2.

## 3. 점접촉 탄성변형 (Level 3 대체 계층)

### 3.1 접촉타원 형상비 χ

ISO 16281 식 (E.1)~(E.3) — ISO p.33 (PDF p.39). ISO 281 식 (B.2)~(B.4) 와 동일.

$$1 - \frac{2}{\chi^{2}-1}\left[\frac{K(\chi)}{E(\chi)} - 1\right] - F(\rho) = 0 \tag{E.1}$$

$$K(\chi) = \int_{0}^{\pi/2}\left[1 - \left(1-\frac{1}{\chi^{2}}\right)\sin^{2}\phi\right]^{-1/2} d\phi \tag{E.2}$$

$$E(\chi) = \int_{0}^{\pi/2}\left[1 - \left(1-\frac{1}{\chi^{2}}\right)\sin^{2}\phi\right]^{+1/2} d\phi \tag{E.3}$$

- (E.1) 은 **χ 에 대한 비선형 스칼라 방정식**이다. `F_i(ρ)` 를 넣으면 `χ_i`, `F_e(ρ)` 를 넣으면 `χ_e` 를 얻는다.
- 타원적분의 모듈러스는 `m = 1 − 1/χ²`. χ ≥ 1 이므로 0 ≤ m < 1.
- **χ 는 하중에 무관**하다. 기하만으로 결정되므로 **해석 시작 시 1회만 풀어 캐시**하면 된다. 이는 매 반복마다 재계산하는 구현 대비 큰 성능 차이를 만든다.

### 3.2 단일 접촉의 탄성변형

ISO 16281 식 (36)(37) — ISO p.15 (PDF p.21)

$$\delta_{i} = \sqrt[3]{4{,}5\left(\frac{1-\nu_{E}^{2}}{\pi E}\right)^{2}}\; K(\chi_{i})\;\sqrt[3]{\frac{\sum\rho_{i}}{\chi_{i}^{2}E(\chi_{i})}}\;Q^{2/3} \tag{36}$$

$$\delta_{e} = \sqrt[3]{4{,}5\left(\frac{1-\nu_{E}^{2}}{\pi E}\right)^{2}}\; K(\chi_{e})\;\sqrt[3]{\frac{\sum\rho_{e}}{\chi_{e}^{2}E(\chi_{e})}}\;Q^{2/3} \tag{37}$$

### 3.3 양측 접촉의 총 탄성변형

ISO 16281 식 (38) — ISO p.15 (PDF p.21)

$$\delta = \sqrt[3]{4{,}5\left(\frac{1-\nu_{E}^{2}}{\pi E}\right)^{2}}\left[K(\chi_{i})\sqrt[3]{\frac{\sum\rho_{i}}{\chi_{i}^{2}E(\chi_{i})}} + K(\chi_{e})\sqrt[3]{\frac{\sum\rho_{e}}{\chi_{e}^{2}E(\chi_{e})}}\right]Q^{2/3} \tag{38}$$

> ISO 16281 §6.1 NOTE (ISO p.14 / PDF p.20, Figure 1): 이 식들은 **양 레이스웨이 사이의 총 변형**, 즉 두 접촉 변형의 합을 정의한다. 내·외륜을 따로 다루는 모델을 쓸 때 이중 계산하지 않도록 주의한다.

### 3.4 하중–변형 관계와 스프링상수

ISO 16281 식 (39)(40) — ISO p.15 (PDF p.21)

$$Q = c_{P}\,\delta^{3/2} \tag{39}$$

$$c_{P} = 1{,}48\,\frac{E_{st}}{1-\nu_{Est}^{2}}\left[K(\chi_{i})\sqrt[3]{\frac{\sum\rho_{i}}{\chi_{i}^{2}E(\chi_{i})}} + K(\chi_{e})\sqrt[3]{\frac{\sum\rho_{e}}{\chi_{e}^{2}E(\chi_{e})}}\right]^{-3/2} \tag{40}$$

하이브리드(강 레이스웨이 + Si₃N₄ 볼), 식 (41):

$$c_{P} = 1{,}48\,\frac{2}{\dfrac{1-\nu_{Est}^{2}}{E_{st}} + \dfrac{1-\nu_{Ece}^{2}}{E_{ce}}}\left[K(\chi_{i})\sqrt[3]{\frac{\sum\rho_{i}}{\chi_{i}^{2}E(\chi_{i})}} + K(\chi_{e})\sqrt[3]{\frac{\sum\rho_{e}}{\chi_{e}^{2}E(\chi_{e})}}\right]^{-3/2} \tag{41}$$

**핵심 대비 — CRB 와의 차이**

| | CRB (선접촉) | BB (점접촉) |
|---|---|---|
| 지수 | `Q = c_L δ^(10/9)` | `Q = c_P δ^(3/2)` |
| `c` 단위 | N/mm^(10/9) | N/mm^(3/2) |
| 계층 | 슬라이스별 `q_k` 합산 | 볼당 **단일** 접촉 |
| 기하 의존 | 프로파일 `Δz(x_k)`, 유효길이 `L_we` | 타원적분 `K(χ)`, `E(χ)`, 곡률합 |

> **주의**: `c_P` 는 **하중에 무관한 상수**다(χ, Σρ 가 기하만의 함수이므로). 즉 볼 하나의 강성 곡선은 해석 전에 완전히 확정된다. CRB 의 슬라이스 강성이 프로파일·트렁케이션에 따라 하중 의존적으로 변하던 것과 근본적으로 다르다.
>
> ISO 16281 §6.1: 결과 비교 가능성을 위해 **§6.2 의 식 집합을 반드시 사용**해야 한다(다른 Hertz 근사식으로 대체 불가).

## 4. 내부 하중분포 — ISO 16281 Annex A.2

### 4.1 전제

Annex A.1 (ISO p.20 / PDF p.26):

> 내부 하중분포는 **정적 평형**으로 계산하며, 원심력·자이로 모멘트 같은 동적 효과는 무시할 만한 것으로 본다. 이 가정은 저·중속, **전형적으로 `n·D_pw < 1×10⁶ mm/min`** 에서 유효하다.

### 4.2 전동체 j 의 탄성변형

식 (A.2) — ISO p.20 (PDF p.26)

$$\delta_{j} = \sqrt{\left(A\cos\alpha_0 + \delta_{r}\cos\varphi_{j}\right)^{2} + \left(A\sin\alpha_0 + \delta_{a} - R_{i}\sin\psi\,\cos\varphi_{j}\right)^{2}}\;-\;A \tag{A.2}$$

> **우변이 음수이면 0 으로 둔다** (하중을 받지 않는 볼). 이것이 접촉/비접촉 스위칭이며, 뉴턴 반복에서 **비평활 지점**을 만든다 → §11 T-3.

기하학적 의미: 하중을 받은 뒤의 두 곡률중심 간 거리에서 무하중 거리 `A` 를 뺀 값. 괄호 안 첫 항이 **반경방향 성분**, 둘째 항이 **축방향 성분**이다.

### 4.3 운전 접촉각

식 (A.5) — ISO p.20 (PDF p.26)

$$\alpha_{j} = \arctan\!\left(\frac{A\sin\alpha_0 + \delta_{a} - R_{i}\sin\psi\,\cos\varphi_{j}}{A\cos\alpha_0 + \delta_{r}\cos\varphi_{j}}\right) \tag{A.5}$$

> **이것이 BB 해석의 본질적 난점이다.** 접촉각이 볼마다 다르고 하중에 따라 변한다. CRB 는 α ≡ 0 고정, TRB 는 α ≈ 상수였다. `atan2` 를 써서 사분면을 보존해야 한다(분모가 음수가 될 수 있음).

### 4.4 정적 평형

식 (A.6)(A.7)(A.8) — ISO p.20 (PDF p.26)

$$F_{r} - c_{P}\sum_{j=1}^{Z}\delta_{j}^{3/2}\cos\alpha_{j}\cos\varphi_{j} = 0 \tag{A.6}$$

$$F_{a} - c_{P}\sum_{j=1}^{Z}\delta_{j}^{3/2}\sin\alpha_{j} = 0 \tag{A.7}$$

$$M_{z} - \frac{D_{pw}}{2}\,c_{P}\sum_{j=1}^{Z}\delta_{j}^{3/2}\sin\alpha_{j}\cos\varphi_{j} = 0 \tag{A.8}$$

전동체 각위치:

$$\varphi_{j} = \frac{2\pi (j-1)}{Z}, \qquad j = 1 \ldots Z$$

> **NOTE (A.2.2)**: 우수좌표계 기준이며 X 축이 베어링 공칭 회전축과 일치한다. 문서 내 모든 그림에서 Y 축은 지면 아래쪽을 향한다.

### 4.5 미지수 구조 — ISO 는 3-DOF 이다

| 미지수 | 대응 방정식 |
|---|---|
| `δ_r` (반경 변위) | (A.6) |
| `δ_a` (축 변위) | (A.7) |
| `ψ` (미스얼라인먼트) | (A.8) |

**즉 ISO 16281 Annex A.2 의 볼베어링 모델은 3-DOF 평면 모델이다.** CRB 프로젝트가 쓰던 5-DOF (δx, δy, δz, γx, γy) 가 아니다. 반경하중이 한 평면 내에 있다고 보고, 그 평면에 `ϕ_j = 0` 을 정렬한 정식화다.

- **3-DOF 로 갈 경우**: ISO 준거가 명확하고 구현이 단순하다. 대신 임의 방향 반경하중·2축 모멘트를 직접 다루지 못하고, 사용자가 하중 평면을 정렬해 주어야 한다.
- **5-DOF 로 확장할 경우**: `δ_r cos ϕ_j → δ_y cos ϕ_j + δ_z sin ϕ_j`, `ψ` → `γ_y, γ_z` 두 성분으로 분리하는 것이 자연스러운 일반화다. Annex A.1 이 "더 복잡한 하중 케이스는 본 문서의 식으로부터 유도할 수 있다" 고 명시적으로 허용한다. 단 이는 **ISO 규정이 아니라 확장**이므로 문서에 그렇게 표기해야 한다.

> 이 선택이 `types.rs` 와 솔버 구조를 가르는 최대 분기점이다 → §12 Plan 결정 항목 D-1.

### 4.6 볼 하중

$$Q_{j} = c_{P}\,\delta_{j}^{3/2}$$

이 `Q_j` 가 §7 수명 계산의 입력이다 (ISO 16281 §5.2.2 가 "정적 평형 해석에서 얻은 `Q_j`" 를 명시).

## 5. 원심력·자이로 모멘트

ISO 16281 A.4 (ISO p.26 / PDF p.32) — **전문**:

> 일반적으로 ISO 15312 의 열 기준속도 이하에서 운전되는 표준 베어링에서는 원심력·자이로힘이 내부 하중분포에 거의 영향이 없어 무시할 수 있다.
>
> 그러나 **매우 고속, 전형적으로 `n·D_pw > 1×10⁶ mm/min`** 에서는 전동체에 작용하는 원심력에 의해 전동체 하중분포가 크게 바뀔 수 있다.
>
> 이 경우 **전동체마다 정적 평형을 계산**하여 원심력·자이로 효과를 고려해야 한다. 통상 이는 링의 정적 평형 계산과 **동시에** 수행되며, 그 결과 계산 모델의 자유도가 크게 증가한다.

**해석**: ISO 는 고속 ACBB 에서 **내륜/외륜 접촉각이 분리**되는 현상(`α_i ≠ α_e`)을 다루는 정식화를 제공하지 **않는다.** A.4 는 "필요성"만 서술하고 식을 주지 않는다.

- CRB 에는 이 계층이 아예 없었다. BB 에서는 **신규 개발 영역**이다.
- 구현하려면 볼당 2개 미지수(`α_i,j`, `α_e,j` 또는 곡률중심 위치)가 추가되어 총 미지수가 `3 + 2Z` 로 늘어난다. 근거 식은 ISO 밖 (Jones 1960, Harris Ch.9 고속 해석) 에서 가져와야 한다.
- **판정 기준식**: `n · D_pw` [mm/min] 를 계산하여 1×10⁶ 초과 시 경고를 띄우는 것이 최소 구현이다.

## 6. 접촉타원과 접촉응력 (Harris Ch.6 보강)

ISO 16281/281 은 `χ`(= a/b) 와 `δ` 만 주고 **접촉타원 반경 `a`, `b` 의 명시식을 주지 않는다.** 설계 판정에 접촉응력이 필요하므로 Harris & Kotzalas Ch.6 의 표준 Hertz 점접촉 정식화로 보강한다 (D-4 결정).

> 기호 대응: Harris `κ` ≡ ISO `χ`, Harris `F(ρ)` ≡ ISO `F(ρ)`, Harris `Σρ` ≡ ISO `Σρ`. **완전히 같은 양이다.**

### 6.1 접촉타원 반경

Harris 식 (6.38)(6.40) — 원서 p.127–128 (육안 확인 완료)

$$a = a^{*}\left[\frac{3Q}{2\Sigma\rho}\left(\frac{1-\xi_{I}^{2}}{E_{I}} + \frac{1-\xi_{II}^{2}}{E_{II}}\right)\right]^{1/3} \tag{H 6.38}$$

$$b = b^{*}\left[\frac{3Q}{2\Sigma\rho}\left(\frac{1-\xi_{I}^{2}}{E_{I}} + \frac{1-\xi_{II}^{2}}{E_{II}}\right)\right]^{1/3} \tag{H 6.40}$$

강–강 접촉 간이형 (식 6.39/6.41, `Q` [N], `Σρ` [1/mm], 결과 [mm]):

$$a = 0{,}0236\,a^{*}\left(\frac{Q}{\Sigma\rho}\right)^{1/3}, \qquad b = 0{,}0236\,b^{*}\left(\frac{Q}{\Sigma\rho}\right)^{1/3} \tag{H 6.39, 6.41}$$

### 6.2 무차원 계수

Harris 식 (6.44)~(6.46). `F`, `E` 는 §3.1 의 `K(χ)`, `E(χ)` 와 동일한 제1·2종 완전타원적분이다.

$$a^{*} = \left(\frac{2\kappa^{2}\mathrm{E}}{\pi}\right)^{1/3} \tag{H 6.44}$$

$$b^{*} = \left(\frac{2\mathrm{E}}{\pi\kappa}\right)^{1/3} \tag{H 6.45}$$

$$\delta^{*} = \frac{2\mathrm{F}}{\pi}\left(\frac{\pi}{2\kappa^{2}\mathrm{E}}\right)^{1/3} \tag{H 6.46}$$

Harris 의 접근량 (식 6.42/6.43):

$$\delta = \delta^{*}\left[\frac{3Q}{2\Sigma\rho}\left(\frac{1-\xi_{I}^{2}}{E_{I}} + \frac{1-\xi_{II}^{2}}{E_{II}}\right)\right]^{2/3}\frac{\Sigma\rho}{2} = 2{,}79\times10^{-4}\,\delta^{*}\,Q^{2/3}\,\Sigma\rho^{1/3} \tag{H 6.42, 6.43}$$

> ⭐ **중요 — 독립 교차검증 경로**: Harris (6.42) 로 구한 단일 접촉 변형은 ISO 16281 식 (36)/(37) 과 **같은 물리량**이다. 서로 다른 두 표준 문헌이 같은 값을 줘야 하므로, 이 일치 여부가 `χ` 솔버와 타원적분 구현의 **가장 강력한 검증**이 된다 (Level B).

### 6.3 접촉응력

Harris 식 (6.25):

$$p_{H,\max} = \frac{3Q}{2\pi ab}$$

판정 기준: ISO 281 Annex B.3.1 이 `σ_Hu = 1 500 MPa` 를 **통상 고품질 재료·양호 가공 베어링의 피로한계 접촉응력**으로 권장한다. 이 값이 `C_u` 산출(§7.9)에도 쓰이므로 응력 판정과 수명 판정이 같은 기준으로 묶인다.

- 스러스트 볼베어링용 (3)(4) 는 `C_a/(Z sin α)` 를 앞에 두고 `1,044` 계수가 없다 — ACBB 단열 레이디얼에서는 사용하지 않는다.
- **§5.2.1.1 단서**: 여기 쓰는 `r_i`, `r_e` 는 `C_r` 계산에 쓴 값과 **동일**해야 한다.

### 7.5 동등가 전동체하중 (ISO 16281 §5.2.2, ISO p.8 / PDF p.14)

내륜이 하중에 대해 **회전**할 때 (통상적인 경우):

$$Q_{ei} = \left(\frac{1}{Z}\sum_{j=1}^{Z} Q_{j}^{3}\right)^{1/3} \tag{5}$$

내륜이 하중에 대해 **정지**일 때:

$$Q_{ei} = \left(\frac{1}{Z}\sum_{j=1}^{Z} Q_{j}^{10/3}\right)^{3/10} \tag{6}$$

외륜이 **정지**일 때 (통상적인 경우):

$$Q_{ee} = \left(\frac{1}{Z}\sum_{j=1}^{Z} Q_{j}^{10/3}\right)^{3/10} \tag{7}$$

외륜이 **회전**할 때:

$$Q_{ee} = \left(\frac{1}{Z}\sum_{j=1}^{Z} Q_{j}^{3}\right)^{1/3} \tag{8}$$

> ISO 단서: 정상적인 하중분포에서 회전/정지 내륜의 차이는 **2 % 미만**이며 내·외륜 편차가 부분적으로 상쇄되므로 일반적으로 무시 가능. **계산 시 통상 내륜 회전·외륜 정지로 본다.**

### 7.6 기본 기준정격수명 (ISO 16281 §5.2.3~5.2.4)

단열:

$$L_{10r} = \left[\left(\frac{Q_{ci}}{Q_{ei}}\right)^{-10/3} + \left(\frac{Q_{ce}}{Q_{ee}}\right)^{-10/3}\right]^{-9/10} \tag{9}$$

복열:

$$L_{10r} = \left(\sum_{m=1}^{i}\left[\left(\frac{Q_{ci}}{Q_{ei\,m}}\right)^{-10/3} + \left(\frac{Q_{ce}}{Q_{ee\,m}}\right)^{-10/3}\right]\right)^{-9/10} \tag{10}$$

동등가 기준하중:

$$P_{ref\,r} = \frac{C_{r}}{L_{10r}^{1/3}} \tag{11}$$

$$P_{ref\,a} = \frac{C_{a}}{L_{10r}^{1/3}} \tag{12}$$

### 7.7 수정 기준정격수명 (ISO 16281 §5.2.5)

단열 ACBB:

$$L_{nmr} = a_{1}\,a_{ISO}\,L_{10r} \tag{13}$$

여기서 `a_ISO` 는 ISO 281:2007 식 (31)~(33) 을 **레이디얼 볼베어링** 곡선으로 쓰되, **인수 `P` 자리에 `P_ref r` 을 대입**한다:

$$a_{ISO} = f\!\left(\frac{e_{C}C_{u}}{P_{ref\,r}},\ \kappa\right)$$

복열 (식 14):

$$L_{nmr} = a_{1}\left(\sum_{m=1}^{i}\left\{a_{ISO\,m}^{-10/9}\left[\left(\frac{Q_{ci}}{Q_{ei\,m}}\right)^{-10/3} + \left(\frac{Q_{ce}}{Q_{ee\,m}}\right)^{-10/3}\right]\right\}\right)^{-9/10} \tag{14}$$

$$P_{ref\,r\,m} = \frac{C_{r}}{i^{7/10}\left[\left(\dfrac{Q_{ci}}{Q_{ei\,m}}\right)^{-10/3} + \left(\dfrac{Q_{ce}}{Q_{ee\,m}}\right)^{-10/3}\right]^{-3/10}} \tag{15}$$

> **§5.2.5.1 제약**: `a_ISO` 는 **강제 볼·강제 레이스웨이**에만 적용된다. 하이브리드 베어링(Si₃N₄ 볼)에는 ISO 281 이 `a_ISO` 를 정의하지 않았다. 식 (41) 로 `c_P` 는 구할 수 있어도 수정수명은 못 구한다.

### 7.8 `a_ISO` — 레이디얼 볼베어링 (ISO 281 식 31~33)

$$a_{ISO} = 0{,}1\left[1 - \left(2{,}5671 - \frac{2{,}2649}{\kappa^{0{,}054381}}\right)^{0{,}83}\left(\frac{e_{C}C_{u}}{P}\right)^{1/3}\right]^{-9{,}3} \quad (0{,}1 \le \kappa < 0{,}4) \tag{31}$$

$$a_{ISO} = 0{,}1\left[1 - \left(2{,}5671 - \frac{1{,}9987}{\kappa^{0{,}19087}}\right)^{0{,}83}\left(\frac{e_{C}C_{u}}{P}\right)^{1/3}\right]^{-9{,}3} \quad (0{,}4 \le \kappa < 1) \tag{32}$$

$$a_{ISO} = 0{,}1\left[1 - \left(2{,}5671 - \frac{1{,}9987}{\kappa^{0{,}071739}}\right)^{0{,}83}\left(\frac{e_{C}C_{u}}{P}\right)^{1/3}\right]^{-9{,}3} \quad (1 \le \kappa \le 4) \tag{33}$$

**적용 한계 (ISO 281 §9.3.3.4)**:
- `a_ISO ≤ 50` 으로 제한. `e_C C_u / P > 5` 인 경우에도 이 상한을 적용.
- `κ > 4` 이면 `κ = 4` 를 사용.
- `κ < 0,1` 이면 계산 불가 (식·선도의 적용 범위 밖).
- EP 첨가제: `κ < 1` 이고 `e_C ≥ 0,2` 이면 `κ = 1` 로 두되 `a_ISO ≤ 3` 으로 제한.

점도비 (ISO 281 식 27~29):

$$\kappa = \frac{\nu}{\nu_{1}} \tag{27}$$

$$\nu_{1} = 45\,000\,n^{-0{,}83}\,D_{pw}^{-0{,}5} \quad (n < 1\,000\ \text{r/min}) \tag{28}$$

$$\nu_{1} = 4\,500\,n^{-0{,}5}\,D_{pw}^{-0{,}5} \quad (n \ge 1\,000\ \text{r/min}) \tag{29}$$

유막 파라미터로부터: `κ ≈ Λ^1,3`.

> ⚠️ **CRB 코드 이식 시 주의**: CRB 는 **롤러용 식 (34)~(36)** (계수 1,5859 / 1,3993 / 1,2348, 지수 0,4 및 −9,185) 을 쓴다. 볼은 **식 (31)~(33)** (계수 2,5671 / 2,2649 / 1,9987, 지수 0,83·1/3 및 −9,3) 이다. 이 계수 세트를 그대로 재사용하면 수명이 틀린다.

### 7.9 피로한계하중 `C_u` (ISO 281 Annex B)

**정밀법 (B.3.2)** — 점접촉이므로 볼은 **해석적으로 계산 가능**하다(롤러와 달리 수치해석 불필요).

$$Q_{u\,i,e} = \sigma_{Hu}^{3}\times\frac{32\pi\,\chi_{i,e}}{3}\left(\frac{1-\nu_{E}^{2}}{E}\times\frac{E(\chi_{i,e})}{\sum\rho_{i,e}}\right)^{2} \tag{B.1}$$

`σ_Hu = 1 500 MPa` (양질 재료·양질 가공 베어링 권장, ISO 281 B.3.1).

$$Q_{u} = \min\left(Q_{ui},\,Q_{ue}\right) \tag{B.9}$$

레이디얼 볼베어링:

$$C_{u} = 0{,}228\,8\,Z\,Q_{u}\,i\cos\alpha \qquad (D_{pw} \le 100\ \text{mm}) \tag{B.10}$$

$$C_{u} = 0{,}228\,8\,Z\,Q_{u}\,i\cos\alpha\left(\frac{100}{D_{pw}}\right)^{0{,}5} \qquad (D_{pw} > 100\ \text{mm}) \tag{B.11}$$

**간이법 (B.3.3)** — `C_0` (ISO 76 정정격하중) 로부터:

$$C_{u} = \frac{C_{0}}{22} \quad (D_{pw} \le 100\ \text{mm}) \tag{B.18}$$

$$C_{u} = \frac{C_{0}}{22}\left(\frac{100}{D_{pw}}\right)^{0{,}5} \quad (D_{pw} > 100\ \text{mm}) \tag{B.19}$$

> ISO NOTE: 간이법 결과는 정밀법과 **상당히 다를 수 있으며 정밀법이 우선**이다.
>
> ⚠️ 롤러용 계수(B.14: 0,2453 / B.20: `C_0/8,2`)와 혼동 금지.

## 10. 적용 범위와 확장

### 10.1 4점접촉 볼베어링

ISO 16281 §5.1 (ISO p.6 / PDF p.12) 명시:

> **4점접촉 볼베어링은 복열 앵귤러콘택트 볼베어링으로 근사**할 수 있다. 단, 반경방향으로 자유롭게 장착되어 주로 축하중을 받아 각 볼에서 **2점 접촉만** 발생하는 경우에 한한다.

즉 ACBB 복열 모델이 완성되면 QJ 는 별도 솔버 없이 커버된다(위 단서 조건 내에서).

### 10.2 깊은홈 볼베어링 (DGBB)

`α₀ = 0` 은 (A.1)(A.2)(A.5) 에서 특이점이 아니다 — `α₀ = arccos(1 − G/(2A))` 가 클리어런스 0에서 0 을 준다. 다만 (A.5) 의 분자가 0 에 가까워져 `α_j` 결정이 민감해지므로 `atan2` 사용이 필수다. **DGBB 는 ACBB 코드의 특수 케이스로 자연 포함**된다.

### 10.3 스러스트 볼베어링

식 (3)(4)(12)(16), `a_ISO` 식 (37)~(39) (`e_C C_u/(3P)` 로 인수가 다름), Annex B.4 (`r_i = r_e = 0,54 D_w`) 로 분기된다. 초기 범위에서 제외.

### 10.4 예압 (Preload)

ISO 16281/281 은 예압을 직접 다루지 않는다. `G_r op` 를 **음(陰)의 클리어런스**로 주거나 `δ_a` 에 초기값을 부여하는 방식으로 표현한다. ACBB 실무에서는 예압이 표준 상태이므로 초기 데이터 모델에 반드시 포함해야 한다 → §12 D-2.
