### G-M4-1 상세 — 임계면·$\hat\tau$ 결정 (병목 해소)

세 후보의 근거를 원문 verbatim으로 확정한다.

**후보1 (선택): 최소외접초구(Minimum Circumscribed hyperSphere) + 대칭화 편차응력의 Tresca**
편차응력 공간에서 하중경로 $S(t)$를 감싸는 **최소 초구의 중심**이 안정화 잔류응력 $-\rho^*$를 주고, 이를 뺀 미시(mesoscopic) 편차 $\hat s(t)$의 **Tresca 반값**이 곧 $\hat\tau(t)$다. 임계면 스캔이 Tresca 안에 내재되어 **명시적 평면 탐색 불필요**.

- **Desimone (33)** `2006. (Desimone) … rolling cont`, Eq(2)-(5):
  - Eq(2): $\tau_{\max}(t)=\dfrac{\hat s_I(t)-\hat s_{III}(t)}{2}$ — *"the instantaneous value of the Tresca shear stress … evaluated over a symmetrized stress deviator"*
  - Eq(5)(최소외접초구 정의): $\max_t[(s_{ij}(t)-s_{ij,m})(s_{ij}(t)-s_{ij,m})]=\min_{s'_{ij}}\max_t[(s_{ij}(t)-s'_{ij})(s_{ij}(t)-s'_{ij})]$
- **Milano/Bernasconi (34)** `2006. (Milano) …`, Appendix Eq(A.1)-(A.4):
  - $\tau_{DV}(t)=\mathrm{Tresca}[\hat s(t)]=\dfrac{\hat s_I(t)-\hat s_{III}(t)}{2}$; $\hat s(t)=S(t)+\rho^*$; $\rho^*=-z^*$;
  - $z^*=z:\min_z\left[\max_t\sqrt{(S(t)-z):(S(t)-z)}\right]$ (← 최소외접초구 중심의 명시식)
- **Dang Van (32) 2003** `2003. (Dang Van) Rolling contact in railways…`, L94: *"in the deviatoric stress space, one constructs the smallest hypersphere surrounding the macroscopic deviatoric stress cycle S = dev, the center of which corresponds approximately to $-\rho$"*; L100-104: *"the maximum value of $\tau(t)$ corresponds to Tresca$(\sigma(t))=\max(\sigma_I(t)-\sigma_J(t))/2$"*; L110: *"the plane which realises the maximum of $\tau(t)=$Tresca$(\sigma(t))$ is also known: the plane where the crack is supposed to initiate is determined"* (→ Tresca가 임계면을 자동 부여).
- **Dang Van (13) 1989** `1989. (DangVan) …`, L166: *"For progressive isotropic hardening the stabilized state occurs for the smallest diameter circle enclosing Γ. We make the assumption that this is a general result."* (초구법의 이론 기원).

**후보2: 증분 "physical" shakedown 알고리즘** (초구 대신 반복 소성 적분)
- **Dang Van (14) 1993** L135-137: *"there are two ways to find $\rho^*$. The first … method based on the theorem of Karatheodory as suggested by Papadopoulos [5]. The second … 'physical' algorithm … The initial elastic domain $C_0$ … As MS follows the loading path Γ … kinematic hardening … isotropic hardening … a limit convex $C_l$ with center $O_l$ … which encloses the whole curve Γ is found. $O_l M$ corresponds to the stabilized"*; 수렴제어 Eq(11) $R_{i+1}=R_i+\chi\epsilon^p_{eq}$, *"$\chi$ should be small … compromise between precision and duration"*.
- **Dang Van (13) 1989** Fig.4·Appendix 1 (L153-166)에 동일 증분 스킴. → 후보1의 초구 중심을 수치적으로 구하는 대안. 정확하나 계산비용↑.

**후보3: 명시적 임계면 전역 스캔 (구면격자 법선 $\vec n$)** — 원 출처가 **회피**
- **Dang Van (32) 2003** L100: *"$\tau(t)$ depends on the direction"* + 원 방식은 각 평면 $\vec n(\theta)$마다 $(\tau,\sigma_H)$를 계산 → **Baietto (36) 2010** `2010. (INSA) …` L156: *"the couple $(\tau,\sigma_H)$ needs to be calculated during the loading cycle on each point for each plane direction, defined by its normal n (and orientation θ). This process is very long and laborious and has been simplified (Dang Van, 1993) assuming Tresca's law is valid."*
- **Dang Van (14) 1993** L200: *"Another alternative is to use the octahedral shear $J_2(\sigma(t))$ instead of $\tau(t)$. This method, however, does not give the critical facets."* → 구면격자 스캔은 방향성(임계면)까지 주지만 비용이 커 원저자들이 Tresca로 대체함.

**선택 근거**: 원 출처 5편 중 RCF에 직접 적용한 Desimone·Milano·DangVan2003이 **일관되게 후보1(최소외접초구→Tresca)** 을 채택하며, Baietto/DangVan1993이 후보3(명시 스캔)을 "비용 과다"로 명시 기각. 따라서 구현 표준은 **후보1**: (a) 각 시간스텝 편차응력 $S(t)$ 수집 → (b) 5차원 편차공간 최소외접초구 중심 $z^*$(=$-\rho^*$) 계산 → (c) $\hat s(t)=S(t)-z^*$ → (d) $\hat\tau(t)=\tfrac12(\hat s_I-\hat s_{III})$, $\hat p(t)=\tfrac13\mathrm{tr}\,\sigma(t)$ → (e) Eq[9]/[11]에 대입.

### 미해결/주의
- **G-M4-3 $N_{ref}$ 수치**: 원 출처(Desimone 포함)에도 **구체 숫자 없음** — 2011은 ">$10^6$"만 명시. 구현 시 "무한수명 기준 $N_{ref}=10^6$(가정)"으로 두고 민감도 확인 필요.
- **잔류응력 상호작용**: Desimone L63·Milano 결론(L264)은 Dang Van이 압축 잔류응력/음의 $\sigma_H$ 조건에서 실험과 불일치함을 경고. 2011 논문(FATIGUE CRITERION L267)도 동일 한계를 인정하되 *"For … rolling contact fatigue without compressive residual stresses, or in fretting conditions, the model has been used with success"* 로 적용 정당화. → 구현은 잔류응력 미포함 가정 하에서 유효.

### G-M4-3 정독 결과 (해소 불가 확정 근거)

Eq(7) $a_{DV}=3(\tau_W/\sigma_W-\tfrac12)$도 N-무관 비(ratio)만 사용.

**(b) Shimizu/JPN (19) — AISI 52100은 관측 가능한 피로한도 자체가 없음**
`2009. (JPN) Probabilistic Stress-Life …`, 결론 L403: *"There is no observable fatigue limit for JIS SUJ2/AISI 52100 bearing steel heat-treated to a hardness of 58-62 HRC. On log-log plotted data, life is linear and is inversely proportional to shearing stress to a 10.34 exponent."* → 피로한도가 없으므로 "$N_{ref}$에서의 $\tau_f,\sigma_f$" 개념이 물리적으로 성립 안 함. **(c) Shimizu (19)가 실제 제공하는 것은 지수형 P-S-N (반-로그 $A\ln N+B$가 아님)**
동 파일 Eq[15] (L381): $N_n=\left(\dfrac{\tau_{\max}}{2.27}\right)^{-10.34}\left(\dfrac{\ln R}{\ln 0.9}\right)^{2/3}+\left(\dfrac{\tau_{\max}}{2.27}\right)^{-9.9}$ (JIS SUJ2/AISI 52100). → **2011 SKF 논문의 $\sigma_f=A\ln N+B$ (A≈−43 MPa, B≈1220 MPa)는 Shimizu에 직접 기재된 값이 아니라, 2011 저자가 이 torsion $\tau_{\max}$–N 데이터를 반-로그로 재적합한 값**임이 재확인됨. ### 공학적 가정 + 민감도 분석 계획 (G-M4-3 대체 처리)

**핵심 논거(가정의 정당성):** 2011 SKF 모델의 계산 경로에서 $N_{ref}$는 **수치로 직접 등장하지 않는다.** 수명은 Eq[11] $1=\max_t\{\hat\tau/((A/\sqrt3)\ln N+(B/\sqrt3)-\alpha\hat p)\}$를 N에 대해 직접 푸는 방식이고, $N_{ref}$는 오직 (i) $\alpha$의 교정 기준과 (ii) $\tau_f=\sigma_f/\sqrt3$ 관계의 준거 사이클로서 **개념적 앵커**일 뿐이다. 또한 $\alpha=(\tau_f-\sigma_f/2)/(\sigma_f/3)$는 $\tau_f/\sigma_f$ **비(ratio)**에만 의존하며, von Mises 가정 하에서 $\tau_f/\sigma_f=1/\sqrt3$는 N에 무관하므로 $\alpha\approx0.232$는 $N_{ref}$ 선택에 **불변**이다. 따라서 $N_{ref}$ 수치 미확정이 모델 예측에 주는 영향은 원리적으로 작다.

**연구자 승인 필요 사항:** (1) $N_{ref}=10^6$ 고정, (2) $A/B$ 재적합값 채택(또는 Shimizu 지수형 직접 사용으로 전환), (3) von Mises $\alpha\approx0.232$ 유지 여부. 위 3건은 원 출처에 확정 수치가 없어 **엔지니어링 판단**이 개입하는 지점이므로, 최종 보고 시 가정으로 명시하고 민감도 결과를 첨부한다.
