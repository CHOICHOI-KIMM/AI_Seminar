# [양식] 논문 구현 — P2-2 검증 데이터 검토서

> **문서 유형**: 검토서 **양식(템플릿)** — P1 착수 전 형식·내용 사전 검토용.
> **대상 논문**: Morales-Espejel & Brizmer (2011) Micropitting Modelling
> **선행 입력**: P1-2 산출물 = **T3 원논문 결과 + T4 해석해/문헌 케이스** (§3.3)
> **통과 게이트**: **G2-2** — 전 검증항목이 게이트(G3/G4/G5)·모듈·오라클에 매핑 · 허용오차·판정기준 확정
> **상태**: ☐ 작성중 ☐ 연구자 더블체크 ☐ G2-2 통과
> **관련**: [[논문 구현 에이전트_v2_r1]] §4 오라클 · [[논문 구현 참고문헌·모델 정리]] §5
> ⚠️ 값은 **예시**. 실제 작성 시 P1-2 인용·원문·디지타이즈 값으로 교체.

---

## 1. 목적·범위

실험 데이터가 없으므로 확보한 **모든 검증 근거(원논문 결과 + 해석해/교과서·문헌)** 를 **어느 게이트에서·어느 모듈을·어느 오라클로·어떤 허용오차로 판정**하는지 하나의 마스터 매핑으로 확정한다. **커버리지 공백 = 검증 gap** 을 드러내는 것이 핵심.

## 4. 게이트별 검증 세트 (실행 묶음)

- **G3 (P3 설계·프로토타입)**: VC-M1-Hertz, VC-M3-Sin, VC-M2-AR, (VC-M4-DV) — 해석해·문헌 케이스로 알고리즘 원리 검증.
- **G4 (P4 모듈 구현)**: VC-M1-Hertz, VC-M3-Sin, CV-Load + 각 모듈 단위 대조.
- **G5 (P5 통합 재현)**: RP-Λmax, RP-Slip, RP-Depth, RP-μbl — 원논문 Fig 재현.

## 5. 허용오차·판정 규칙 정의

| 등급 | 대상 | 규칙 |
|---|---|---|
| 정량(엄격) | 해석해(①) | 상대오차 ≤ 1~2% |
| 보존(엄격) | ② | ≤ 0.1% |
| 정성(곡선) | ③ | **극값 위치·단조성·형태 일치**(값 자체보다 경향) |
| 정량(스팟) | ④ | 물리 스케일 일치(예: 깊이 ±1µm) |

> 원논문이 "정성적 일치"만 주장하므로 ③은 **형태 재현**을 판정기준으로 한다(과적합 방지).
