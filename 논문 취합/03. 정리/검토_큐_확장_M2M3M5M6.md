## 우선순위 요약 (차단·재귀 순)

1. **A-1 / C(암묵) G-M3-1a** — **3D 6응력 원전 Tripp 2002 확보**: M3 완결의 재귀 병목. 미확보 시 β=0 부분검증만 가능 → **최우선 발주**
2. **C-1 (G-M6-1)** — **EHL 중앙유막 공식·계수 서명 + ~20% 민감도**: h̄가 결과 최상위 민감, **높음 리스크**
3. **A-2 / B-2 / C-5 (G-M5-2)** — **u_s→사이클당 거리 차원 정합**: 마모율 정량 차단, "차원 일치" 주장 모순 해소
4. **C-2 (G-M2-1)** — 비뉴턴 상보파 진폭 매핑(ME2010 미보유) 대체안+민감도 서명
5. **C-3 (G-M2-3)** — cavitation 절단 오차 게이트 대체 승인
6. **C-4a~e** — 미확정 수치 Gap 5건(ψ임계·flow tol·DC규약·φ_bl완화·k_lub) 가정+민감도 일괄 승인
7. **A-4 / B-6~B-8** — M5·M6 원전 미보유(OCR 단일의존) 셀 전수 정본 재확인 또는 범위밖 승인
8. **B-1 / B-3 / B-4** — OCR 정정(η_x·ζ·e^{-ζz})·z샘플링 상충·FFT 규약 원문 대조 서명
9. **C-6 / C-7** — E′ 2배 규약·α 삼중 명명분리(내용 확정, 서명만 잔여)

> **완결성 크리틱 종합**: 이론·알고리즘·검증 G1은 통과하나, **M3(원전 재귀), M6(공식 민감도), M5(차원 정합)** 3개가 실질 차단 요인이다. 특히 M5·M6은 검증자 오라클 밖 원출처(OCR 단일의존)라 근거신뢰도가 M2·M3보다 구조적으로 낮다. 미확정 수치 Gap은 모두 "침묵 없이 가정+민감도"로 정직 표기되어 있어 사인오프 절차만 남았다.
