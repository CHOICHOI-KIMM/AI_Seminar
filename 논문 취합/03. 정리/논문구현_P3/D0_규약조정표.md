# D0 — 규약조정표 (Convention Reconciliation Table)

P3 Phase 0 공유 기반 crate `micropitting-model` 의 **코드 SSOT ↔ 논문 ↔ CRB** 규약 매핑.
전략 B(표준/CRB 정렬)를 채택한다. 모든 코드는 SI 단위(m, Pa, s, N)로 계산하며, 외부값은
경계에서 `crate::units` 헬퍼로 변환한다.

---

## 1. 핵심 물리량 매핑

| 항목 | 코드 SSOT (`micropitting-model`) | 논문 관례 | CRB (`CRB-main`) | 조정(변환) |
|------|-----------------------------------|-----------|-------------------|------------|
| 환산탄성계수 | `e_red` [Pa], `1/E_red=(1-ν₁²)/E₁+(1-ν₂²)/E₂` | `E'` (여러 문헌: `2/E' = (1-ν₁²)/E₁+(1-ν₂²)/E₂`) | `e_star` = E_red 정의와 동일(단, GPa/MPa) | **`E' = 2·E_red`** (`E_PRIME_FACTOR=2.0`, 1회 치환) |
| 길이/유막/간극 | m | 혼용(m, μm) | mm, μm | `mm_to_m`, `um_to_m` |
| 압력/응력 | Pa, **인장 +** | Pa/GPa | MPa(내부), GPa(입력) | `gpa_to_pa`; 접촉압력 크기는 관례상 양수 저장 |
| 선하중 w' | N/m | N/m | N/mm (`q_k`) | `n_per_mm_to_n_per_m` (×1e3) |
| 점도 η₀ | Pa·s | Pa·s | Pa·s (ν·ρ 로 산출) | 동일 |
| 압점도계수 | `alpha_visc` [Pa⁻¹] | α [Pa⁻¹] | `alpha_pv` [nGPa⁻¹→Pa⁻¹] (×1e-9) | `inv_gpa_to_inv_pa` |

### alpha 명명 분리 (혼동 방지, SSOT)
| 이름 | 단위 | 의미 |
|------|------|------|
| `alpha_visc` | Pa⁻¹ | 압력-점도계수 (Barus/Roelands) |
| `alpha_wave` | 1/m | (후속) 파수/공간 주파수 |
| `alpha_dv` | 무차원 | (후속) 무차원 계수 |

### 좌표계 (SSOT)
접촉 패치 로컬. **x = 구름방향**, **y = 횡방향**, **z = 깊이(+, 표면 아래로 증가)**.
거칠기 높이장은 x·y 양방향 주기(FFT 순환 컨볼루션 전제). `Field2` 레이아웃은 row-major
`index = i + j·nx` (i=x, j=y).

## 2. 지배식 "논문형 → 표준형(코드)" 변환

### 2.1 Hertz 선접촉 (`util::hertz::hertz_line`)

- **논문형(E' 사용):** `b = √(8·w'·R/(π·E'))`, `p₀ = 2w'/(π·b)`
- **표준형(코드, E_red):** `b = √(4·w'·R/(π·E_red))`, `p₀ = 2w'/(π·b)`
- **동치성:** `E' = 2·E_red` 대입 시 `8/E' = 8/(2E_red) = 4/E_red` → 두 식 일치.
- **회귀검증:** 강-강(E₁=E₂=210e9, ν=0.3) → `E_red≈115.4e9`; w'=1e5 N/m, R=0.01 m
  → `b≈1.05e-4 m`, `p₀≈6.06e8 Pa`. (테스트 통과)

### 2.2 Dowson-Toyoda 중심유막 (`util::film::dowson_toyoda_hc`)

- **무차원 군(CRB 정렬, E_red 직접 사용):**
  `U = η₀·u_mean/(E_red·R)`, `G = α_visc·E_red`, `W = w'/(E_red·R)`
- **중심유막:** `H_c = 3.06·U^0.69·G^0.56·W^(-0.10)`, `h_c = H_c·R` [m]
- **보정 제외:** 열보정 φ_t, 기아보정 φ_s 는 **미포함**(순수 smooth 값). CRB
  `compute_film_thickness` 는 `h_c·φ_t·φ_s` 를 반환하나 본 함수는 곱하지 않음.
- **E_red vs E' 주의:** Dowson-Toyoda 계수(3.06·지수)는 원래 `E'` 기반 유도.
  본 구현은 **CRB 정렬(E_red 직접 대입)** 을 SSOT 로 고정(CRB `compute_film_thickness`
  와 bit 정합). `E'` 규약으로 엄밀 재현이 필요하면 U,G,W 에 `E'=2E_red` 대입.
- **회귀검증:** η₀=0.01, u=1, α=2e-8, E_red=115.4e9, w'=1e5, R=0.01
  → `h_c≈1.39e-7 m` (≈0.14 μm). (테스트 통과)

## 3. 인터페이스 계약(동결)

`types.rs` 의 struct 는 M1/M2/M6 공유 SSOT:
`Grid`, `Field2`, `MaterialProps`, `OperatingConditions`, `PartialLubInput`,
`DryResult`, `LubResult`, `PartialLubResult`. 모든 필드 SI + 단위 주석.
serde 미사용(순수 struct). 상수: `E_STEEL_PA`, `NU_STEEL`, `E_RED_STEEL_PA`,
`E_PRIME_FACTOR=2.0`, `EPS=1e-12`.

## 4. 미결/후속(Phase M1~M6)
- M1 `solve_dry`: 반공간 변형 + 상보성 압력해 (현재 스텁).
- M2 `solve_full_film`/`solve_partial`: Reynolds+EHL 연성 (현재 스텁).
- M6 `combine_share`: 압력장 합성 + φ_bl 하중분율 (현재 스텁).
- 열/기아 보정(φ_t, φ_s)은 M2 단계에서 별도 도입(본 Phase 0 유틸은 순수식만 동결).
