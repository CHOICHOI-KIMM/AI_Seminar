원 SKF 2011 논문이 Dang Van 응력이력 τ̂/p̂ 계산법을 "will not be discussed here"로 부재 처리해 **G-M4-1**(M4 최대 난점)로 남았으나, `2006. (Desimone) On the application of Dang Van criterion to rolling cont_58b30a.md`(repo 보유) 원문 직접 정독 결과 **실무 계산법 전체가 식(1)~(7)로 명시**됨을 확인 → gap 실질 해소. verbatim:

- **식(1)** `τ_max(t) + a_DV·σ_H(t) = τ_W` — 파손 locus (τ_W=역전 비틀림 피로한계).
- **식(2)** `τ_max(t) = ½(ŝ_I(t) − ŝ_III(t))` — **대칭화 편차응력의 Tresca**(주값 ŝ_I≥ŝ_II≥ŝ_III).
- **식(3)** `s_ij(t) = σ_ij(t) − δ_ij·σ_H(t)`, `σ_H(t) = ⅓ tr σ(t)` — 편차·정수압.
- **식(4)** `ŝ_ij(t) = s_ij(t) − s_ij,m` — 대칭화(상수텐서 감산).
- **식(5) [MCE 정의]** `s_ij,m` 은 `maxₜ[(s(t)−s_m)·(s(t)−s_m)] = min_{s'} maxₜ[(s(t)−s')·(s(t)−s')]` 를 만족 — **편차응력경로 {s_ij(t)} 의 최소외접초구 중심**(Chebyshev center). 피로 크랙핵생성에 무영향인 편차분을 최소화로 제거.
- **식(7)** `a_DV = 3(τ_W/σ_W − ½)` — τ_W/σ_W=1/√3(von Mises) → **a_DV≈0.232** 확정. Desimone 경고: 강재는 τ_W/σ_W>0.5 가능 → 민감도.
- **식(6)** 잔류 시 `τ_max(t) + a_DV[σ_H(t) + σ_H,res] = τ_W` — 잔류는 **정수압에만** 가산.

### 3b. VC-M3-Hertz "실피크"의 정확한 의미 + <1% 결선 (2026-07-14 보강)

**"실피크"란 무엇인가**: VC-M3-Hertz 오라클은 매끈 Hertz 선접촉 압력 `p(x)=p_h√(1−(x/b)²)`(|x|<b)를 **M3 솔버**(2D-FFT→식[10]/[16] FRF→IFFT)에 입력해 얻은 **표면하 von Mises 응력의 축상(on-axis) 최대값**이다. 이를 두 값과 대조:
- **고전 기준(McEwen)**: 고립(비주기)·무한 반공간 Hertz 선접촉의 축상 최대 vM = **0.5575·p_h @ z≈0.70b**(교과서 폐형식, 원문 아님·외부 독립앵커).
- **솔버 실피크**: M3가 실제 산출한 값. 즉 "솔버가 매끈 Hertz에 대해 내놓는 표면하 vM 최대가 고전값을 얼마나 재현하는가"의 척도(구현 정확도 측정).

**왜 편향이 났나 (물리적 원천)**: 솔버는 **주기적 FFT**(유한창)로 계산하나 McEwen은 **고립·무한** 해다. 두 원천:
1. **평균압(DC) 아티팩트 [지배]**: Hertz 범프는 창 평균이 0이 아님(p̄≈π/64·p_h≈0.049p_h). 주기 프레임에선 이 평균이 **전 표면 균일하중**으로 취급돼 전 깊이에 구속 응력을 더한다 — **고립 Hertz엔 없는 성분**. p̄∝1/창.
2. **이미지 하중·이산화**: 이웃 주기 범프(±창 간격)·격자 유한성 기여(작음).

**<1% 결선 (2단계, 전부 근거·실측)**:
- (a) **DC 측방항 교정**: `σ_xx=σ_yy=0` → `ν/(1−ν)σ_zz`(구속 균일하중 고전 참응답, Hooke `ε_lat=0`서 유도) → +7.1%→+3.4%(32b창).
- (b) **대형창 수렴**: 오차∝1/창 **실측**(32b→+3.4%, 64b→+1.80%, 128b→+0.93%, 256b→+0.49%). **dx를 b/32→b/64로 세분해도 불변**(0.93%→0.91%) → 편향은 **순수 창(DC) 효과**이지 이산화가 아님을 확증. **256b·nx8192 채택 → +0.49%(<1%)**. 피크 깊이 z/b=0.699(고전 0.70과 정합).

**정합의 의미**: **깊이(0.70b)는 처음부터 정확**했고 편향은 오직 피크 크기(주기-평균 아티팩트)에 있었다. 대형창 수렴은 "주기 FFT로 비주기 접촉을 검증"하는 표준기법(zero-pad→창→∞)이라 **정당한 수렴이며 masking 아님**. 대안=평균분리(P2-3 §3.3, 작은 창서 DC를 해석적으로 제거)이나 대형창이 등가·단순. **실사용(거칠기 리플)엔 평균압이 물리적**이라 DC 구속응답이 옳고 대형창은 **검증 셋업 한정**(솔버 불변).

### 3c. 접선(q) DC "완전형" 설명 + 대안 + 결선 (2026-07-14)

**무엇이었나(잔여의 실체)**: DC(ζ=0) 모드는 하중장의 **공간평균**이다. 법선 평균(p̄)은 §3b에서 다뤘고, **접선 평균(q̄=μ·p̄)** 의 표면하 응답이 "접선 DC 완전형"이다. Tripp FRF 는 ζ→0 에서 in-plane 항(`a²/ζ²`)이 0/0 이라, 애초 에이전트는 접선 DC 를 "τ_xz=q_DC·나머지 0"의 **최소선택**으로 두고 근거·검증을 잔여(RQ-M3-DC)로 표기했었다.

**물리적 참값(유도)**: 반공간에 **균일 표면전단 `τ_xz(x,y,0)=q`** 를 가하면 내부는 **단순전단(simple shear)** 상태가 된다:
- `σ_xz = q`(전 깊이 불변), **나머지 5성분 = 0**, `σ_vM = √3·q`.
- 근거: 이 응력장이 (i) 평형 `∂σ_ij/∂x_j=0`, (ii) 적합성(변위 `u_x=(q/G)·z`, 단순전단), (iii) 경계조건 `σ_zz(0)=0·τ_xz(0)=q·τ_yz(0)=0` 을 **모두 만족하는 유일 응력해**. 변위 `u_x∝z` 는 깊이에서 무한대로 발산하나(균일 무한전단의 퇴화성) **응력은 잘 정의**된다. ζ→0 서 다른 접선 FRF 성분들의 방향-비결정(0/0)은 이 단순전단해에 의해 **0 으로 확정**된다.
- → **현 구현(τ_xz=q_DC, 나머지 0)이 정확히 이 참값**. 즉 접선 DC 는 **원래 올바랐고**, 없던 것은 검증 오라클뿐이었다.

**결선(채택)**: 검증 오라클 **`dc_uniform_traction`** 추가 — 균일 q → `σ_xz=q`(전 깊이)·나머지 0·vM=√3·q 확인(통과). 이로써 접선 DC 도 **정본 확정**. (dc_uniform_pressure=법선 구속하중, dc_uniform_traction=접선 단순전단 — 두 DC 응답 모두 검증됨.)
- **변이게이트 2/2 CAUGHT(검출력 증명)**: (M1) 접선 DC 제거 `xz:qhat→z0` → "τ_xz DC != q" FAIL; (M2) 허위 성분 주입 `xy:z0→qhat` → "τ_xy DC != 0" FAIL. 둘 다 오라클이 포착 후 정확 원복(코드 무변경·70+2 green). 즉 `dc_uniform_traction` 은 "정확 성분 누락"과 "허위 성분 추가"를 모두 검출 → tautology 아닌 실효 오라클.

**대안(고려·비교)**:
| 대안 | 내용 | 판정 |
|---|---|---|
| **① 검증 오라클(채택)** | 균일 q→단순전단 오라클로 접선 DC 확정 | **채택**(저비용·직접 폐색) |
| ② 평균분리(P2-3 §3.3) | 평균(p̄·q̄) 을 분리해 매크로장을 **해석적**(감쇠하는 Hertz/Cerruti)으로, FFT 는 zero-mean 리플만 | 실사용 매크로 정밀도용 rigorous 대안; **리플(비-DC) 목적엔 불요 → enhancement 이월** |
| ③ 대형창 | 검증 시 평균 ∝1/창→0 (Hertz 에 이미 적용) | 고립접촉 검증 한정 |
| ④ 검증 시 DC 제외 | 고립접촉 검증서 DC(유한창 아티팩트) 배제 | 검증-특화·비권장(실사용 DC 는 물리적) |

**결론**: 접선 DC 는 단순전단으로 **정본 확정·검증 완료**(①). RQ-M3-DC 의 **법선·접선 DC 응답은 모두 해소**. 남는 것은 "실사용 매크로장 정밀도"뿐인데, 이는 **평균분리(②, P2-3 §3.3)** 로 처리할 **enhancement** 이며 M3 의 본 목적(거칠기 **리플** 응력=비-DC 모드, 정확)엔 불필요. 정량 매크로 Hertz 정합이 필요할 때 ② 착수.
