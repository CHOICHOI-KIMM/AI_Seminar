### 2.1 ⚙ G-M3-1 재추출 확정 — Tripp 2003 원전 (핵심 갱신)

**확정 판정: 6응력 폐형식의 정본은 Tripp et al. 2003 "Frequency Response Functions and Rough Surface" 식[10](법선)·식[16](트랙션).** 확장 초안의 "Tripp(22, 2002) 미보유 → 재귀 병목(☐ 미충족)"은 **해소**된다. 후속 논문 식[12][13]은 이 원전의 재인용이다.

**(A) 법선압력 $p_0$ 6응력 — Tripp 2003 식[10] (verbatim, $\zeta=\sqrt{\alpha^2+\beta^2}$):**
```
σ_x = p₀[α²/ζ² − α²z/ζ + 2ν(β/ζ)²] e^{−ζz} cos(αx)cos(βy)
σ_y = p₀[β²/ζ² − β²z/ζ + 2ν(α/ζ)²] e^{−ζz} cos(αx)cos(βy)
σ_z = p₀(1 + ζz) e^{−ζz} cos(αx)cos(βy)
τ_xy = −p₀(αβ/ζ²)[(1−2ν) − ζz] e^{−ζz} sin(αx)sin(βy)   ← 원문 라벨 τ_zy는 오식, 실제 τ_xy
τ_yz = p₀(βz) e^{−ζz} cos(αx)sin(βy)
τ_xz = p₀(αz) e^{−ζz} sin(αx)cos(βy)
```

**(B) 표면 트랙션 $q_0$ 6응력 — Tripp 2003 식[16] (verbatim):**
```
σ_x = q₀(α/ζ)[2 + 2ν(β/ζ)² − (α/ζ)(αz)] e^{−ζz} sin(αx)cos(βy)
σ_y = q₀(α/ζ)[2ν(α/ζ)² − (β/ζ)(βz)] e^{−ζz} sin(αx)cos(βy)
σ_z = q₀(αz) e^{−ζz} sin(αx)cos(βy)
τ_xy = q₀(β/ζ)[1 − 2ν(α/ζ)² − (α/ζ)(αz)] e^{−ζz} cos(αx)sin(βy)
τ_yz = q₀(β/ζ)(αz) e^{−ζz} sin(αx)sin(βy)
τ_xz = q₀[1 − (α/ζ)(αz)] e^{−ζz} cos(αx)cos(βy)
```

> ⚠️ **중대 발견 — 2011 식[13] σ_y 전사 오류**: 2011 식[13] 2행 `σ_y = q₀(α/δ)[2υ(β/δ)² − (α/δ)(αz)]…`은 원전 식[16] `[2ν(α/ζ)² − (β/ζ)(βz)]`와 **두 군데 손상**($(α/ζ)²→(β/ζ)²$, $(β/ζ)(βz)→(α/ζ)(αz)$; δ=ζ OCR). **구현에는 반드시 Tripp 2003 식[16] 원본 사용.** trace 오라클로 정본 확증(아래).

**확정 사항**: β≠0 교차항(τ_xy, τ_yz), 부호(법선 τ_xy는 음, Poisson 결합 (1−2ν)), Poisson 계수(σ에 2ν 교차), 공통 감쇠 $e^{−ζz}$(z>0=물체 내부), 표면압력 $\sigma_z(x,y,0)=p_0\cos\cos$ 항상 양(+) — 모두 verbatim 검증.

**해소된 하위 Gap:**
- **부호·z 규약(구 G-M3-1b/1c)**: z>0=내부(inward normal), 감쇠 $e^{−ζz}$, $\zeta>0$. 인장양수 규약. **M4 Dang Van 정수압 $\hat p$ 부호 인계 시 규약 명시 필수**(모듈 경계 항목).
- **FFT 정규화(구 G-M3-1c)**: 실표면 z(xᵢ,yⱼ) 2D-FFT로 정현모드 분해 → 각 (α,β)에 식[10]/[16] 적용(선형) → 합산 IFFT. 비주기 처리 = large window + zero-padding(주기성 오차 지배, Polonsky-Keer). 2011 식[1] $u(p)=\mathrm{IFFT}\{w\cdot\mathrm{FFT}(p)\}$의 FRF $w$가 이 폐형식에서 유도.
- **z 샘플링(구 G-M3-1d)**: 원전 "Rolling in a Rough Lubricated Groove" 예제 = **z/a=0~0.25, 30 등간격점**(128×128 면내). 과제의 z=0~0.25a·15층은 이 범위의 절반 해상도 축약으로 **원전 범위와 정합** → 샘플링 창 물리근거 확보.

**검증 오라클(사인오프 Q9 범례 적용):**
- ①**해석해**: 모든 성분 = 압력진폭 × 무차원괄호 × $e^{−ζz}$ × 삼각함수 → bi-harmonic 정확해(수치해 아님).
- ②**보존/차원 (trace 오라클, 정본 판별)**: $\sigma_x+\sigma_y+\sigma_z$ 가 정확히 $2(1+\nu)$ 형태로 축약 →
  - 식[10]: $=2(1+\nu)p_0 e^{−ζz}\cos(αx)\cos(βy)$ ✓
  - 식[16]: $=2(1+\nu)q_0(α/ζ)e^{−ζz}\sin(αx)\cos(βy)$ ✓
  - **2011 식[13] 손상 σ_y로는 이 축약 불성립** → 원전 식[16]이 정본임을 역증명.
- ③**극한 오라클**: β=0 → 식[10]→식[4](1D 법선), 식[16]→식[7](1D 트랙션), τ_xy·τ_yz→0. z=0에서 경계조건 식[8]/[9] 충족.
- ④**정량**: Hertz $\sigma_{vM}/p_H=0.557$ @ z/b≈0.73(2003 Table1) 재현.

### 2.2 ⚠ G-M4-1 임계면법 — 사인오프 Q3 단일 채택

**판정: MCE + 대칭화 편차응력의 Tresca를 구현표준으로 단일 채택(사인오프 확정).**

- **확정 근거**: 2011은 $\hat\tau(\vec n,t)$·$\hat p(t)$ 결정을 5개 참조(13,14,33,34,36)로 명시 회피("this will not be discussed here"). RCF 직접적용 3편(Desimone·Milano·DangVan2003)이 일관되게 MCE→Tresca 채택, Baietto·DangVan1993은 명시 구면격자 스캔을 "비용 과다"로 기각. **임계면은 Tresca에 내재되어 명시 탐색 불요.**
- **저자 의도 처리(사인오프)**: 2011 저자 실제 의도는 논문 본문에서 확인 불가능한 추론이나, **Q3에서 MCE+Tresca 단일 채택으로 확정**. 등가 대안(증분 shakedown)은 동일 초구 중심을 수치로 구하는 대안으로 **VC-M4-DV 오라클(Milano/Desimone 닫힌해)로 일치 검증**.
- **파이프라인**: (a) 각 시간스텝 편차응력 $S(t)$ 수집 → (b) 5차원 편차공간 최소외접초구 중심 $z^*(=-\rho^*)$ → (c) $\hat s(t)=S(t)-z^*$ → (d) $\hat\tau(t)=\tfrac12(\hat s_I-\hat s_{III})$, $\hat p(t)=\tfrac13\mathrm{tr}\,\sigma(t)$ → (e) 식[9] $D=\max_t\{\hat\tau/(\tau_f-\alpha_{DV}\hat p)\}$ / 식[11] 대입. $\alpha_{DV}\approx0.232$(von Mises $\tau_f/\sigma_f=1/\sqrt3$).

### 2.3 G-M4-3 Wöhler A/B — 사인오프 Q4 확정

- **확정값(SO Q4)**: **A = −43.0 MPa (음부호 확정)**, **B = 1220 MPa**. $\sigma_f=A\ln N+B$가 N 증가 시 감소해야 함으로 음부호 물리 확정.
- **출처 귀속(1라운드 정정 유지)**: A/B는 **Shimizu 원문 값이 아니라 2011 저자가 Shimizu(19) torsion τ_max–N 데이터를 반-로그 재적합한 값**(2011 L112/L117 verbatim). Shimizu는 반-로그 회귀 부적절을 명시(L123)했으므로 이는 원저자 견해와 배치되는 단순화임을 기록.
- **$N_{ref}$**: SO Q8로 $N_{ref}=10^6$ 가정 승인. $\alpha_{DV}=(\tau_f-\sigma_f/2)/(\sigma_f/3)$는 $\tau_f/\sigma_f$ **비**에만 의존 → $N_{ref}$에 불변. 민감도 $N_{ref}\in\{10^6,10^7\}$.
