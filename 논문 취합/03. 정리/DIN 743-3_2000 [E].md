This standard was worked out by experts from the Standardizing Committee for Machine Manufacture (NAM) in the DIN German Institute for Standardization e.V., Motive Power Engineering (Ant, AA 2.2) and the Institute for Machine elements und Machine construction of TU Dresden.

## 1 Range of applications

This standard includes details for the strength parameters of materials required for the verification of strength by DIN 743-1. If the user has his own drawn values or conclusions, he can use these details in his calculations.

## 4 Strength values of materials

Scope of strength values:

– The strength values are valid for the temperature range $- 4 0 ^ { \circ } \mathsf { C } \le \mathsf { \boldsymbol { \theta } } \le 1 5 0 ^ { \circ } \mathsf { C } .$

Above $\theta = 1 5 0 ^ { \circ } \mathrm { C }$ the strength values fall back by more than 10%, and temperature dependent strength values must be taken into account.

– Frequency range upto 100 Hz.

– The strength values are valid for the ultimate number of stress cycles

$$
\dot { N } _ { \mathsf { G } } = 1 0 ^ { 7 } .
$$

– Round bending and flat bending are not differentiated. The fatigue

strength values are given for the unfavourable round bending.

The characteristic values are valid for material samples with diameter d<sub>B</sub> (see appendix A) or for half-finished goods with almost the same diameter.

The characteristic values for tensile strength σ<sub>B</sub> correspond to the lower limit of the range suitable for small nominal values (nominal diameter d<sub>B</sub>) which are given in the metallurgical standards. The characteristic values for elastic limit σ<sub>S</sub> correspond to the lowest values suitable for small nominal measurements (nominal diameter d<sub>B</sub>) by these standards.

In case the characteristic values for tensile strength and elastic limit given in this standard are evidently overshot, even the other characteristic values can be correspondingly increased.
