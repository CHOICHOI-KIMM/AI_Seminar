# 논문 구현 — P2-2 검증데이터 검토서 **재검토** (P3 구현 반영, 전 6모델)

> **문서 유형**: `논문 구현_P2-2_검증데이터검토서_통합_M1-M6.md`(P2 시점 정본)의 **재검토판**. 원본 P2-2 는 **보존**하고 본 파일에서만 정정·보강한다.
> **목적**: P2-2 의 해석해/문헌해 검증항목을 **원문(문헌) ↔ P2-2 ↔ P3 코드 오라클** 3자 재대조하여 (1) P2-2 인용·값·출처 정확성 정정, (2) P3 구현에서 발견/추가된 오라클·RQ 반영, (3) 코드 정합 실측 연결.
> **작성일**: 2026-07-15 · **선행**: P3 구현(M1~M5 crate, `cargo test` 87단위+2통합 green; 브랜치 P3_M5).
> **핵심 원칙**: **코드 동결**(본 재검토는 문서 산출물만; 코드 정정이 필요한 『코드이월』은 §3 이월과제로 기록만). **불필요한 적대 크리틱 제외** — 해석해/문헌해 정합(독립·비퇴화·허용오차)만으로 검증.

## 등급 범례 (재검토 신설)
- **A급 (해석해/문헌 정량 정합) = 진짜 검증**: 독립 문헌값·비퇴화·허용오차 내 재현.
- **B급 (구조/보존/차원/극한/정성)**: 물리 타당성 보조.
- **C급 (자기정합·대수 항등·가정+민감도)**: 회귀가드일 뿐 검증 아님(정직 표기).

## 불일치 유형 (3자 대조 — 한글 표기)
- **『P2-2정정』**: 원문 ≠ P2-2 → **P2-2 를 원문 기준 정정**(본 재검토 반영).
- **『코드이월』**: 원문=P2-2 ≠ 코드 → **코드 정정 이월과제**(§3, 코드 동결).
- **『상태갱신』**: P2-2 ↔ 코드 값·허용오차·상태 상이(원문 무관) → 실측 기록·상태 갱신.
- **『신규등재』**: P2-2 에 없는 P3 오라클 등재(문서화 gap, 사실오류 아님).

## 표 열 정의 (§1 재대조표 8열)
`오라클 | 등급 | P2-2 원문 기대값 | 출처/본문(참고문헌 번호) | 재확인 결과(O/X) | 코드 실측 | 일치여부(O/X) | 정정 계획`
- **재확인 결과** = P2-2 ↔ 원문(P2-2 인용값·출처가 원문과 맞는가). **O**=일치 / **X**=불일치(개조식+유형).
- **일치여부** = 코드 ↔ 정본(코드 실측이 정본을 재현하는가; 최종 판정). **O**=일치 / **X**=불일치(개조식+유형).
- **정정 계획** = 정정 필요(X·신규·상태갱신) 시만 개조식.
