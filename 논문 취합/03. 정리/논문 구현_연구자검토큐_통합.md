# 논문 구현 — 연구자 검토 큐 (통합, 전 6모델 M1~M6)

> **목적**: 무인 Workflow가 생성한 두 검토 큐를 **단일 연구자 액션 문서**로 통합. 서명/조치 완료 시 **G2 전면 통과**.
> **대상**: P2-1/2-2/2-3 초안 — 파일럿(M1·M4) + 확장(M2·M3·M5·M6). **G1 전 6모델 3/3 통과, G2는 조건부**(연구자 사인오프 전).
> **출처 큐**: [[검토_큐_파일럿_M1M4]] · [[검토_큐_확장_M2M3M5M6]] (원본 세부는 각 파일 참조)
> **작성일**: 2026-07-07
> **ID 규약**: 우선 차단순 마스터 번호(Q#) + 출처태그 `[P]`=파일럿(M1M4) `[X]`=확장(M2M3M5M6). 완료 시 ☑.

> ⚠️ **중요 정정(통합 시 확인)**: 확장 큐의 "M5·M6 원출처(Archard 17·Williams 37·ME 2010 21·Johnson 23) 미보유·OCR 단일의존"은 **부분적 하네스 아티팩트**다. 해당 4편은 실제로 `03. 정리/`에 **모두 보유** 중이며, 다만 확장 실행의 G1 크리틱에 전달된 오라클셋(6파일)에 포함되지 않아 "독립대조불가"로 표기되었다. → **재검증 시 이 4편을 오라클에 포함하면 대부분 해소**된다(진짜 외부 gap 아님). 진짜 외부 미보유는 **Tripp 2002**뿐(§5).
