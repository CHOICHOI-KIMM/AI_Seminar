## 1. 연구 목적

원통 롤러 베어링(CRB)에 외부 모멘트/장착 오차가 가해지면 롤러에 불균일 하중이 발생하여 변형이 생김. 기존 방법으로는 롤러 변형을 정확히 시뮬레이션하기 어려움. **빔 기반 슬라이싱 기법**을 새롭게 제안하여 롤러 탄성 변형을 고려한 동역학 모델 개발.

---

## 2. 슬라이싱 기법 비교 — 핵심 기여

논문에서 3가지 슬라이싱 기법을 비교:

### 2.1 Hertz 접촉 기반 (기존 방법 1 — Appendix A)

- 각 슬라이스 독립적으로 처리
- $q_l = K_{Hertz} \cdot \delta_l^{10/9}$
- 슬라이스 간 **상호작용 무시** → 정확도 최하

### 2.2 영향계수 기반 (기존 방법 2 — Appendix B)

- 반무한체 이론 기반 유연성 계수 $D_{ij}$
- 슬라이스 간 영향 고려
- 롤러 축이 **변형되지 않는다고 가정** → 한계

### 2.3 빔 기반 슬라이싱 (본 논문 제안) — 핵심

- 각 슬라이스에 **독립 6-DOF** 부여: $X_i = [x_i, y_i, z_i, \theta_{xi}, \theta_{yi}, \theta_{zi}]^T$
- 인접 슬라이스 간 **Timoshenko 빔 스프링/감쇠** 연결
- 슬라이스 간 구속력:

$$F_{i-1}^l = -[K](\Delta X - \Delta X_0)$$

| 계수 | 의미 |
|------|------|
| $K_{11} = EA/2h$ | 축방향 강성 |
| $K_{22} = 12EI_{zz}/[(2h)^3(1+P_y)]$ | 전단 보정 굽힘 강성 |
| $K_{44} = GI_{xx}/2h$ | 비틀림 강성 |
| $K_{55} = (4+P_z)EI_{yy}/[2h(1+P_z)]$ | 회전 강성 |
| $P_{y/z}$ | Timoshenko 전단 변형 계수 |

**FEM 대비 가장 높은 정확도** (커플링 + 개별 슬라이스 강체 모두 고려)

## 4. 동역학 모델 (Section 3)

### 4.1 좌표계
- 7개 좌표계: 외륜 고정, 내륜 고정, 케이지 고정, 롤러 고정, 포켓, 슬라이스, 슬라이스 방위각

### 4.2 슬라이스별 힘/모멘트
- **내륜 접촉**: $q_{jk}^i = K_{Hertz} \cdot (\delta_{jk}^i)^{10/9}$
- **마찰력**: Wang의 견인 모델 (윤활 특성 4개 파라미터 A, B, C, D)
- **케이지 접촉**: 포켓 법선력 + 마찰력
- **교반 저항**: $f_{jk}^l \propto \rho_v \cdot L/n \cdot D_w \cdot \omega$
- **가이드링 유체 동압**: Sommerfeld 형태

### 4.3 운동 방정식
- Newton-Euler 방정식
- 자유도: $6 \cdot (n \cdot Z + 1) + 3$ (기존 모델의 $n$배)
- **Newmark-β 알고리즘**으로 풀이

### 4.4 검증
- NU215 베어링, 2400/3600 rpm
- 케이지 속도 실험 측정 대비 **오차 5% 이내**

## 5. 동적 거동 분석 결과

### 5.1 반경 하중 (Y축) 효과
- 접촉 하중 크기 및 변화 주파수 증가
- **주파수 스펙트럼**: 롤러 통과 주파수의 정수배
- 큰 반경 하중 → 슬라이딩 억제
- **슬라이딩 속도는 공전 속도에 크게 의존** (자전보다 중요)

### 5.2 Y축 모멘트 효과
- 접촉 하중 피크값 **감소**
- 접촉 영역 **확대**, 최대 응력 **감소**
- 과도한 모멘트 시 최대 응력 위치가 1개 → 2개로 분리
- 부하/비부하 영역 간 슬라이딩 속도 차이 증가

### 5.3 Z축 모멘트 효과
- 접촉 하중에 거의 영향 없음
- 최대 접촉 응력 위치가 축방향으로 이동
- 슬라이딩에 대한 영향은 Y축 모멘트보다 작음

---

## 6. 주요 결론

1. **빔 기반 슬라이싱**이 FEM과 가장 잘 일치 (탄성 변형 고려)
2. 롤러 변형으로 인해 **풍부한 주파수 스펙트럼** 발생 (롤러 통과 주파수의 정수배)
3. 슬라이딩 속도는 **공전 속도에 의해 결정** → 높은 공전 속도로 슬라이딩 최소화
4. Y축 모멘트는 부하 영역 확대, 최대 접촉 응력 감소 → **피로 수명 연장 가능**

## 7. TRB 프로젝트와의 관련성

| Yan 모델 | TRB 프로젝트 매핑 |
|----------|-------------------|
| Hertz 기반 슬라이싱 (독립) | **Gen1 솔버** — 각 슬라이스 독립 |
| 빔 기반 슬라이싱 (Timoshenko) | **Gen3 솔버** — Timoshenko 빔 FE 커플링 |
| 영향계수 기반 | Teutsch/Sauer AST와 유사한 중간 접근 |
| 6-DOF 슬라이스 | Gen3에서 2-DOF(w, θ)로 단순화 가능 |
| $K_{Hertz} \cdot \delta^{10/9}$ | `hertz.rs`의 Palmgren 접촉 지수 |
| Newmark-β 동적 풀이 | 현재 프로젝트는 준정적이므로 직접 해당 없음 |
| 로그 프로파일 트리밍 | `geometry.rs`의 Logarithmic crown type |

**핵심 시사점:**
- 본 논문은 TRB 프로젝트의 **Gen1(독립) ↔ Gen3(빔 커플링) 구조가 올바른 접근**임을 독립적으로 확인
- 빔 기반이 영향계수 기반보다 정확하다는 것은 Gen3의 Timoshenko 빔 접근의 타당성을 뒷받침
- 다만 본 논문은 CRB(원통)이므로, TRB(테이퍼)에서는 접촉각/리브 접촉 등 추가 고려 필요
