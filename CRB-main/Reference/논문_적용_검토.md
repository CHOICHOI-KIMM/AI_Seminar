## 1. 하중-변위 관계식 개선 — Teutsch (2004)

### 현재 구현 (`hertz.rs`)

현재 `solve_q_from_delta()`는 **Tripp 암묵적 수식**을 Newton-Raphson으로 반복 풀이:

```
δ = (2q)/(πE*) × [ln(4R/b) - 0.5]   ← 암묵적 (b도 q의 함수)
```

매 슬라이스마다 NR 반복 ~50회 → Gen1에서 n_slices × Z_rollers × 반복 = 상당한 계산량.

### Teutsch 제안: Dinnik 기반 명시적 curve-fit

```
δ_i = 3.17 × (d_m/2)^0.08 × (Q(1-ν²)/(EL))^0.92   (내륜)
δ_o = 2.66 × (t/(1+D/d_m))^0.09 × (Q(1-ν²)/(EL))^0.91   (외륜)
```

**장점:**
- Q ↔ δ **양방향 직접 계산** (반복 불필요)
- FEM 대비 오차 < 1.5%
- 내/외륜 별도 계수로 레이스웨이 두께(t) 효과 반영

### 적용 판단: ⚠️ 참고만 (직접 적용 보류)

| 항목 | 판단 |
|------|------|
| 계산 속도 개선 | O — NR 반복 제거로 Gen1 속도 2~3배 향상 가능 |
| 정확도 | △ — Teutsch 식은 **균일 단면 원통 롤러** 기준. TRB의 테이퍼 형상에서는 슬라이스별 등가반경 R_k가 달라지므로 직접 적용 시 보정 필요 |
| 현재 방식의 문제 | 현재 Tripp 암묵적 식도 정확하고, NR 수렴이 안정적. 병목이 아님 |
| **권고** | **현재 Tripp+NR 유지**, 향후 파라메트릭 스위프 속도가 문제되면 Teutsch 식 도입 검토. 내/외륜 분리 계수(`c_i`, `c_o`)는 참고할 가치 있음 |

## 2. 영향계수 행렬 (AST) — Teutsch (2004)

### 현재 구현: Gen1(독립) vs Gen3(Timoshenko 빔)

Gen1과 Gen3 사이에 **중간 정확도 모드**가 없음.

### Teutsch 제안: 가중 영향계수 행렬 [S_w]

슬라이스 간 변형 상호작용을 1/r 가중함수로 근사:

```
w_{j,k} = (1/r_{j,k})^(1/ex)   (j≠k)
w_{j,k} = (4/l)^(1/ex)          (j=k)
[S_w]{q} = {Δ}  → 가우스 소거로 풀이
```

### 적용 판단: ❌ 불필요 (Gen3가 상위 호환)

| 항목 | 판단 |
|------|------|
| 정확도 | Yan (2025)에서 확인: 영향계수 방법 < 빔 기반 방법 < FEM |
| 구현 복잡도 | Gen3와 비슷한 행렬 풀이 필요 |
| 프로젝트 구조 | 이미 Gen1(빠름) ↔ Gen3(정확) 이원 체계 확립 |
| **권고** | **적용하지 않음.** Gen3의 Timoshenko 빔이 AST보다 물리적으로 정확하고 이미 구현 완료. AST는 역사적 참고로만 가치 있음 |

## 3. Timoshenko 빔 슬라이싱 검증 — Yan (2025)

### 현재 구현 (`beam.rs` + `gen3.rs`)

- 2-DOF/node (w, θ): 횡변위 + 회전
- Timoshenko 전단 보정: Φ = 12EI/(κGA L²)
- 원형 단면 전단 보정 계수: κ = 10/(9+10ν)
- 테이퍼 형상: 요소별 r_avg로 EI_k 계산

### Yan 제안: 6-DOF/node 슬라이스

Yan은 각 슬라이스에 **6자유도** (x, y, z, θ_x, θ_y, θ_z) 부여:
- K₁₁ = EA/2h (축방향)
- K₂₂ = 12EI/(2h)³(1+P) (굽힘)
- K₄₄ = GI_xx/2h (비틀림)
- K₅₅ = (4+P)EI/2h(1+P) (회전)

### 적용 판단: ✅ 부분 적용 (검증 + 향후 확장 참고)

| 항목 | 판단 |
|------|------|
| 현재 2-DOF 충분성 | **현재로서 충분.** TRB 정적/준정적 해석에서 롤러 축방향 변형(K₁₁)과 비틀림(K₄₄)은 무시 가능. 횡방향 굽힘이 지배적 |
| Yan의 6-DOF 필요 조건 | 동역학(케이지 상호작용, 슬라이딩), 스큐/틸트 효과 분석 시 필요 |
| **즉시 적용 가능 항목** | |
| ① FEM 대비 검증 근거 | Yan 논문의 비교 결과(빔>영향계수>Hertz 독립)를 Gen3 검증 문서에 인용 |
| ② 전단 보정 계수 검증 | Yan의 P_y/P_z 산식과 현재 κ 계산 비교 → 일치 확인 |
| ③ 로그 프로파일 식 | Yan의 Eq.(5): `C_s = A·ln[1-(2x/L)²]⁻¹` → `geometry.rs`의 Logarithmic crown에 직접 활용 가능 |
| **향후 확장 시** | 동역학 모델 추가 시 6-DOF 확장 참고 |

## 4. 베어링 레벨 모델링 — Stirling (2023)

### 현재 구현 (`bearing.rs`)

- 5-DOF 평형: [δx, δy, δz, γx, γy]
- 블록 분해 NR: Phase A(힘 2×2) → Phase B(모멘트 2×2)
- Gen1만 사용 (베어링 루프 내)
- 모멘트 반력: 외부 모멘트 M 입력 시 Phase B 활성화

### Stirling의 핵심 발견

1. **모멘트 반력이 DTRB 모델링의 필수 요소** — 현재 구현에 이미 반영됨 ✅
2. **모멘트가 베어링 변위의 주 드라이버** — 풍력 터빈 등 대형 응용에서 중요
3. **토셔널 스프링 강성 추정** — FEM에서 추출
4. **가변 강성**: 내부 모델의 비선형 강성이 해석 모델의 일정 강성 가정과 불일치

### 적용 판단: ✅ 부분 적용

| 항목 | 판단 |
|------|------|
| 5-DOF 평형 | ✅ 이미 구현. Stirling과 동일한 접근 |
| 30개 라미나 | ✅ `SolverParams.n_slices` 기본값 30~50으로 설정 — Stirling 권고와 일치 |
| **적용 항목** | |
| ① 가변 강성 반영 | `bearing.rs`의 현재 NR은 매 반복마다 롤러 하중을 재계산하므로 **암묵적으로 가변 강성 반영됨.** 별도 조치 불필요 |
| ② 엣지 로딩 경고 | Stirling이 관찰한 "일관된 엣지 로딩" → `generate_alerts()`에 **슬라이스 레벨 엣지 응력 경고** 추가 필요 |
| ③ 루프 하중 구조 시각화 | 극좌표 하중 플롯(힘-모멘트 루프) → 프론트엔드 `ResultCharts`에 반영 고려 |
| ④ 듀얼 열 모델 | 현재는 단열(single-row) TRB. 이중열(DTRB) 확장 시 Stirling의 모델 구조 참고 |

## 5. ISO 16281 피로 수명 — Stirling (2023)

### 현재 구현 (`life.rs`)

```rust
pub fn compute_fatigue_life(...) -> Result<FatigueLifeResult, SolverError> {
    Err(SolverError::NotImplemented("Fatigue life (Phase 5)".into()))
}
```

**아직 미구현 상태.**

### Stirling의 피로 수명 접근

- 라미나별 기본 동정격하중: `q_ci = Q_ci × (1/n_s)^(7/9)`
- 응력 상승 함수: `f_i[k] = 1 - (0.01/ln(1.985/|...|))` (비크라운 프로파일)
- 로그 프로파일 시 단위 함수 (f=1) 제안
- 수정 수명: `L_nm = a_ISO × L_10` (κ, 오염도, 온도 함수)

### 적용 판단: ✅ 직접 적용 (Phase 5 구현 시)

| 항목 | 적용 방안 |
|------|----------|
| 라미나별 수명 계산 | `life.rs` 구현 시 Stirling의 식을 기본 틀로 사용 |
| 응력 상승 함수 | 두 가지 옵션 제공: (a) ISO 표준 함수, (b) Stirling 단위 함수 (로그 프로파일용) |
| 내/외륜 분리 | `L_10_inner`, `L_10_outer` 별도 계산 → 이미 `FatigueLifeResult`에 필드 존재 |
| 민감도 분석 | 윤활 점도(κ), 온도, 오염도 파라미터 → `OperatingConditions`에 이미 `nu_40`, `nu_100`, `T_op` 있음 |

## 6. 로그 프로파일 수식 통일 — Teutsch + Yan + Stirling 공통

### 현재 구현 (`geometry.rs`의 Logarithmic crown)

현재 코드를 확인 필요하지만, 3개 논문 모두 동일한 Reusner/Lundberg 로그 프로파일 사용:

```
Δz(x) = A × ln[1 / (1 - (2x/L)²)]
```

### 적용 판단: ✅ 수식 일치 확인 필요

`geometry.rs`의 `CrownType::Logarithmic { A_log }` 구현이 위 수식과 일치하는지 검증. 3개 논문 모두 동일 수식이므로 **교차 검증의 기준점**으로 활용.

## 결론

3개 논문은 TRB 프로젝트의 **Gen1↔Gen3 이원 구조가 올바른 접근**임을 독립적으로 확인해준다.

- **Teutsch**: Gen1(독립)과 Gen3(커플링)의 중간에 AST를 제안했지만, Yan이 빔 기반이 더 정확함을 입증 → Gen3 선택이 정당
- **Stirling**: TRB 베어링 레벨 모델의 실무적 요구사항(5-DOF, 30 라미나, 모멘트 반력)을 확인 → 현재 구현과 잘 부합
- **Yan**: Timoshenko 빔 기반 슬라이싱이 FEM과 가장 잘 일치 → Gen3의 이론적 타당성 뒷받침

**가장 큰 실질적 기여**: Stirling의 피로 수명 계산 방법론 → `life.rs` 미구현 상태이므로 Phase 5에서 핵심 참고 자료.
