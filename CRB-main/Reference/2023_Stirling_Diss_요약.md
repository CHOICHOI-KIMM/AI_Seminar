# Stirling (2023) — 풍력 터빈 TRB 메인 베어링 내부 하중 모델링 핵심 요약

**원제:** Internal Load Modelling of Tapered-Roller Main Bearings in Wind Turbines
**저자:** James Stirling (PhD 학위논문)
**소속:** University of Strathclyde, Glasgow (Wind and Marine Energy Systems CDT)
**발표:** 2023년 7월

---

## 1. 연구 목적

풍력 터빈 메인 샤프트에서 **이중열 구면 롤러 베어링(DSRB)의 조기 파손** 문제 해결을 위해 **이중열 테이퍼 롤러 베어링(DTRB)**이 대안으로 제안됨. 그러나 DTRB의 풍력 터빈 적용 시 하중 거동이 거의 연구되지 않은 상태. 이 논문은 DTRB의 **내부 하중 분포 모델 개발** 및 **운전 특성 분석**을 목표로 함.

---

## 2. 연구 질문 3가지

1. DTRB 메인 베어링을 **어떻게 간단하고 효율적으로 모델링**할 수 있는가?
2. 이 모델로 **운전 조건, 하중 드라이버, 피로 수명 민감도**에 대해 무엇을 알 수 있는가?
3. DTRB의 하중 거동이 **DSRB와 어떻게 다른가**?

---

## 3. 모델 개발 (Ch.3~4)

### 3.1 드라이브트레인 해석 모델 (Ch.3)

- 3점 마운트(SMB) 드라이브트레인의 **해석적 모델** 개발
- **FEM 모델**(DSRB/DTRB 두 가지)과 비교 검증
- DSRB 모델: 기존 해석 모델과 잘 일치
- **DTRB 모델: 기존 해석 모델로는 부정확** → 모멘트 반력 능력이 필수적
- **토셔널 스프링** 추가로 DTRB의 모멘트 반력 특성 반영 → FEM과 좋은 일치

### 3.2 내부 하중 분포 모델 (Ch.4) — 핵심

- **SKF 331555B** 베어링 기반 (풍력 터빈용 DTRB)
- **슬라이싱 기법**: 롤러를 30개 라미나(lamina)로 분할
- 각 라미나의 접촉 하중: **Palmgren 선접촉 관계** ($q_k = C_k \cdot \delta_k^{10/9}$)
- **5-DOF 평형**: 축방향, 반경방향, 각도 변위 ($\delta_a, \delta_r, \gamma$) → 옵티마이저로 풀이
- 비선형 강성 특성 내재 (롤러/라미나 수에 따라 강성 변화)
- **가변 강성 기능**: 해석 모델의 일정 토셔널 강성 가정의 영향 분석 및 보정 방법 제안

### 3.3 모델 특징 비교

| 특징 | 본 모델 | 해석 모델 | 다물체 모델 | FEM |
|------|---------|----------|-----------|-----|
| 계산 시간 | 낮음 | 매우 낮음 | 낮~중 | 높~매우 높음 |
| 교차 결합 강성 | O | X | O | O |
| 내부 하중 | O | X | O | O |
| 접촉 응력 | 확장 가능 | X | O | O |
| 다른 응용 통합 | O | O | X | 비실용적 |

## 4. 주요 발견 사항

### 4.1 하중 특성

- **모멘트 하중이 베어링 변위의 주 드라이버** (반경 하중보다 중요)
- 정상 운전 중 **"루프형" 하중 구조** 발견 (힘-모멘트 극좌표에서 루프 패턴)
- **롤러 엣지 로딩이 일관되게 발생** → 프로파일링의 중요성
- 두 롤러열이 **동시에 하중을 분담** (DSRB와 근본적 차이)

### 4.2 DTRB vs DSRB 비교 — 핵심 차이

| 항목 | DSRB | DTRB |
|------|------|------|
| 모멘트 반력 | 없음 (자동 조심) | 있음 (모멘트 지지) |
| 하중 분담 | 거의 하류열만 지지 | 양 열이 항상 분담 |
| 풍속 전단 증가 시 피로 수명 | **증가** (로터 "리프트" 효과) | **감소** (모멘트 증가) |
| 모델링 시 모멘트 반력 | 불필요 | **필수** |

### 4.3 피로 수명 민감도 분석 (Ch.5)

- **ISO 16281 기반** 피로 수명 계산 (라미나별 응력 상승 함수 포함)
- 로그 프로파일 롤러 가정 → 단위 응력 상승 함수 제안

**민감도 순서 (피로 수명에 미치는 영향):**

| 순위 | 인자 | 영향 |
|------|------|------|
| 1 | **풍속 전단 지수** | 가장 큰 영향 (0.2→0.4에서 수명 급감) |
| 2 | 난류 강도 | 높은 난류 → 수명 감소 |
| 3 | 윤활유 점도/온도 | 점도 감소 → 수명 감소 |
| 4 | 평균 풍속 | 정격 풍속 부근에서 수명 최저 |

## 5. 결론 및 향후 과제

### 결론
1. DTRB 모델링 시 **모멘트 반력 능력 포함이 필수**
2. 모멘트 하중이 내부 변위의 **주 드라이버**
3. DTRB와 DSRB의 하중 거동은 **근본적으로 다름** (일부는 정반대)
4. 풍속 전단이 피로 수명에 가장 큰 영향
5. DSRB에서 개발된 경험을 DTRB에 맹목적으로 적용해서는 안 됨

### 향후 과제
- 프리로드 및 미정렬 효과 추가
- 롤러 마찰 효과 분석
- 엣지 로딩으로 인한 균열 파손 모드 연구
- 비상 정지/시동 등 과도 이벤트 시뮬레이션
- 다물체 동역학 모델과의 통합

## 6. TRB 프로젝트와의 관련성

| Stirling 모델 | TRB 프로젝트 매핑 |
|---------------|-------------------|
| 30개 라미나 슬라이싱 | Gen1 솔버의 기본 접근 |
| Palmgren $\delta^{10/9}$ 접촉 | `hertz.rs`의 접촉 지수 |
| 5-DOF 평형 (δa, δr, γ) | `bearing.rs`의 베어링 평형 |
| 비선형 강성 | Gen1/Gen3 모두 해당 |
| 엣지 로딩 관찰 | 프로파일 보정 (`geometry.rs`)의 중요성 확인 |
| ISO 16281 피로 수명 | `life.rs` 구현 시 참고 |
| 응력 상승 함수 | 라미나별 피로 계산에 활용 |
