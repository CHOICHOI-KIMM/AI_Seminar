# 조사 계획 (업데이트) — 거칠기 피크 보존 모델링 → FFT 압력해석 [부록 4]

> **목적:** 거칠기의 **피크 돌기를 보존·표현**하는 수학적 도구를 체계 조사하고, FFT 기법으로 상세(피크 포함) 압력분포를 얻는 경로를 확립. 단순 1회 조사가 아니라 **지속 연구 확장의 토대(living foundation)** 로 운용 — 각 논문의 **계보도·저널·인용수 기반 영향도**를 누적 관리.
> **산출물:** 본문 `분석_MixedEHL_공학적활용.md` **부록 4(신규)** = 합성 정리 / 본 파일 = 계획 + 영향도·계보 트래커(누적 갱신).
> **연계:** 부록1(고속 결정론 파이프라인)·부록3(통계/스펙트럼, dry+윤활 현황).

## 1. 조사 4축 (수식까지)

| 축 | 내용 | 핵심 질문 | 수식 대상 |
|---|---|---|---|
| **A. 표면 표현·생성** | PSD+위상 스펙트럼 합성, 디지털 필터 생성, 비가우시안 marginal | 측정 PSD·skew·kurtosis 목표로 피크 보존 표면 생성법? | ACF/PSD↔필터, Johnson 변환식 |
| **B. 비가우시안·프랙탈** | skew/kurtosis 제어, 멀티스케일 피크 | 실제 베어링 표면 피크를 어떤 분포족·프랙탈이 재현? | W–M 함수, 프랙탈 차원 $D$, $Sk,Ku$ 생성 |
| **C. 피크·summit 통계** | 평균 회피·극값으로 피크 특성화, 해상도 의존성 | 평균을 피하며 피크를 통계 정량화? $m_4$ 발산 처리? | 스펙트럼 모멘트 $m_0,m_2,m_4$, summit PDF, 극값 |
| **D. 거칠기→압력 (FFT)** | 단일 실현 결정론 FFT-접촉, 윤활 결합 | 생성/측정 표면→피크 압력분포 $O(N\log N)$? | DC-FFT 합성, CG+MLMS, 변분식 |

(축 D 이후 압력→6응력→피로는 부록1·3에 기수록 → 본 조사는 A~D 집중, D에서 부록1과 접속)

## 2. ★신규: 논문 영향도·계보 프레임워크

### 2.1 논문별 수집 항목 (트래커 컬럼)
1. 서지: 저자·연도·제목·**저널**·권/페이지·DOI
2. **저널 등급**(분야 위상: 예 *J. Tribol.*/*Wear*/*Proc.R.Soc.*/*JMPS* 등)
3. **인용수**(Google Scholar/Crossref, **수집일 명기** — 시변값)
4. **계보 역할**: 창시(foundational) / 확장(extension) / 응용(application) / 리뷰(review)
5. **계보 링크**: parents(무엇을 토대로) / children(무엇이 이를 계승) → 인용 트리
6. **베어링 표면 표현력**(핵심 질문 #3): 실제 표면 대비 검증 여부·정성 점수(상/중/하)
7. 피크 보존 여부(평균/실현/극값) · 해상도 의존성 메모

### 2.3 영향도 정리 방식
- **1차 분류:** 저널 위상 × 인용수 → "핵심 줄기(backbone)" vs "주변·특수" 분리.
- **2차:** 계보 역할(창시/확장/응용/리뷰)로 종축 구성 → **시간순 계보도** 작성.
- **3차(핵심 질문 #3):** "베어링 표면 표현력" 컬럼으로 **실측 대비 검증된 모델**을 별도 하이라이트 → 연구 확장 우선순위.
