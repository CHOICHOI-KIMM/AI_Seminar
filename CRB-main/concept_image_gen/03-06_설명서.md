## 1. 배경: 왜 윤활 해석이 필요한가

테이퍼 롤러 베어링(TRB)에서 롤러와 궤도면(내륜/외륜)은 **직접 금속끼리 닿지 않는다**. 그 사이에 극히 얇은 윤활유 막(유막, film)이 존재하여 두 표면을 분리한다.

```
외륜 표면  ─────────────────────────
         ~~~~ 유막 (0.1~1μm) ~~~~     ← 이 얇은 막이 핵심
롤러 표면  ─────────────────────────
```

이 유막이 **충분히 두꺼우면** 금속 접촉이 없어 베어링이 오래 간다.  
유막이 **너무 얇으면** 표면의 미세한 거칠기(조도) 봉우리끼리 부딪혀 마모, 피팅, 균열이 발생한다.

**윤활 해석의 목적**: 운전 조건(속도, 하중, 온도, 윤활유 종류)에서 유막이 얼마나 두꺼운지 계산하고, 그것이 베어링 수명에 어떤 영향을 미치는지 평가하는 것.

## 2. 이미지 #3: EHL 모델 아키텍처

### EHL이란?

**EHL** = Elastohydrodynamic Lubrication (탄성유체윤활)

일반적인 윤활(기름이 두 면 사이를 채움)과 달리, 베어링 접촉부에서는 두 가지 특수한 현상이 동시에 일어난다:

1. **탄성 변형**: 접촉 압력이 매우 높아(1~3 GPa) 강철 표면이 탄성적으로 찌그러진다
2. **유체 역학**: 기름이 좁은 틈으로 끌려 들어가면서 압력이 생기고, 이 압력이 다시 표면을 밀어낸다

이 두 현상이 **서로 연결**되어 있어서 "탄성(Elasto) + 유체역학(Hydrodynamic)" = EHL이라 부른다.

### 이미지 #3의 3+1 구조

이미지에서 4개 모델을 **경험식 3개 vs 수치해석 1개**로 분류한다:

#### 왼쪽: Empirical (Closed-form) — M1, M2, M3

수많은 수치 시뮬레이션 결과를 **한 줄 공식**으로 피팅(curve-fitting)한 것. 입력을 넣으면 유막 두께가 바로 나온다. 빠르지만 근사값이며, 출력은 대표값(스칼라) 하나.

#### 오른쪽: Numerical (PDE Solver) — HMEHL만

물리 방정식(Reynolds 방정식)을 직접 컴퓨터로 풀어서 접촉부 내 **위치별** 압력, 유막, 온도 분포를 구한다. 정확하지만 느리다.

#### 4개 모델 요약

| 모델 | 분류 | 핵심 | 언제 쓰나 |
|------|------|------|----------|
| **M1 (DH)** | 경험식 | 1977년 Dowson-Higginson 공식. 입력 최소, 계산 최속. 거칠기 무시. | 빠른 초기 검토, ISO 표준 수명 계산 |
| **M2 (MK)** | 경험식 | 2012년 Masjedi-Khonsari 공식. 거칠기 효과를 유막 공식에 통합. 고압 점도 모델(Roelands) 사용. | **설계 실무 권장 (Recommended)** |
| **M3 (NVM)** | 경험식 | 1994년 Venner-Moes 공식. 4가지 윤활 영역(저속~고속, 저하중~고하중)을 하나로 통합. | 논문 비교/검증, 향후 볼 베어링 확장 |
| **HMEHL** | 수치해석 | Reynolds PDE + Multigrid + FBNS + TEHL. 위치별 분포 P(x), h(x), T(x) 출력. | 최고 정밀도, 연구용, 압력 스파이크 해석 |

세 경험식 모두 최종적으로 동일한 **Λ → Regime → κ → a_ISO** 파이프라인으로 수명 계산에 연결된다.

### M1 vs M2 vs M3: 왜 M2가 Recommended인가

세 모델은 모두 경험식(한 줄 공식)이지만, 물리적 정교함과 커버리지가 다르다. 아래에서 7가지 관점으로 비교한다.

#### (1) 조도(표면 거칠기) 처리 — 가장 큰 차이

이것이 M2를 "Recommended"로 만드는 **핵심 이유**다.

```
M1/M3의 접근 (2단계):
  ① 유막을 매끈 표면 기준으로 계산 → h_smooth
  ② 나중에 거칠기와 비교 → Λ = h_smooth / σ

M2의 접근 (1단계 통합):
  ① 거칠기가 유막 형성 자체를 변화시킨다고 공식에 반영
     h_MK = h_smooth × rc(σ̄)    ← rc < 1 (거칠면 유막 감소)
```

**왜 중요한가**: 실제 베어링 표면은 완벽하게 매끈하지 않다(Rq ≈ 0.15~0.3 μm). 혼합윤활(Λ < 3) 영역에서는 거칠기가 유막 형성에 직접 영향을 미친다. M1/M3는 이를 무시하므로 유막을 **낙관적으로 과대 예측**한다.

| 동일 조건 | M1 유막 | M2 유막 | 차이 |
|----------|---------|---------|------|
| Λ > 3 (양호) | 100% | ~95% | 미미 |
| Λ ≈ 2 (혼합) | 100% | ~80% | **M2가 20% 얇게** |
| Λ ≈ 1 (경계) | 100% | ~60% | **M2가 40% 얇게** |

혼합윤활에서 M1은 "괜찮다"고 하지만 M2는 "위험하다"고 경고할 수 있다. **보수적이지만 현실적**.

#### (2) 압력-점도 모델

| | M1 | M2 | M3 |
|---|---|---|---|
| 모델 | **Barus** `η = η₀·e^(αp)` | **Roelands** (비선형) | **Roelands** (비선형) |
| 고압 정확도 | 0.5 GPa 이상에서 과대 | 정확 | 정확 |

Barus는 수학적으로 단순하지만, 실제 기름은 고압에서 Barus보다 점도 증가가 완만하다. TRB 접촉압은 1~3 GPa이므로 Barus의 과대 예측이 유막을 두껍게 만든다(역시 낙관적).

#### (3) 열보정 (고속 시 유막 감소)

| | M1 | M2 | M3 |
|---|---|---|---|
| 모델 | **Gupta** (속도만) | **Murch-Wilson** (속도+SRR) | Murch-Wilson |
| SRR 의존 | 없음 | **있음** | 있음 |

**SRR** = Slide-Roll Ratio(슬라이딩 비). TRB의 리브 접촉은 순수 슬라이딩이므로 SRR이 크다. M1의 Gupta는 이 슬라이딩 발열을 무시하여 유막을 과대 예측한다.

#### (4) 기아보정 (기름 공급 부족)

| | M1 | M2 | M3 |
|---|---|---|---|
| 방식 | **사용자 입력** φ_s | **사용자 입력 + 물리 기반 자동 병행** | M2와 동일 |
| 그리스 보정 | 없음 (경험적 0.5~0.8) | 블리딩 계수 자동 (사용자 오버라이드 가능) | M2와 동일 |

M1은 사용자가 φ_s를 직접 입력해야 한다.

M2/M3는 두 값 중 **작은 것**을 사용하는 보수적 로직:
- 사용자가 φ_s = 1.0(기본값)으로 두면 → 물리 기반 자동 계산값 사용
- 사용자가 φ_s < 1.0을 입력하면 → `min(사용자 입력, 자동 계산)` → 더 보수적인 쪽 채택

즉 **UI에서 그리스 φ_s를 직접 입력하면 그 값이 자동 계산보다 우선**할 수 있다(단, 자동 계산이 더 작으면 자동 계산이 우선).

#### (5) 트랙션(마찰) 모델

| | M1 | M2 | M3 |
|---|---|---|---|
| EHL 마찰 | **간이 Eyring** `μ = τ₀/p` | **완전 Eyring + Roelands** | 완전 Eyring |
| SRR 의존 마찰 | 없음 (상수) | **있음** (sinh⁻¹ 모델) | 있음 |
| Flash 온도 | 없음 | **Blok-Jaeger** | Blok-Jaeger |

M1은 마찰 계수가 압력에만 의존하는 상수. M2는 슬라이딩 비, 유막 두께, 압력, 점도가 모두 반영된 물리 기반 마찰. 동력 손실, 발열 분석에 필수.

#### (6) 혼합윤활 모델 (유막 + 조도 접촉 공존)

| | M1 | M2 | M3 |
|---|---|---|---|
| 하중분배 | **Greenwood-Tripp** (별도 후처리) | **M-K 내장** (유막 공식에 통합) | M2 공유 |
| 조도 하중분율 | F₅/₂(Λ) 적분 | 0.50·exp(−0.70·Λ^0.50) | M2 공유 |

M1은 유막 계산과 조도 계산이 분리된 2단계 접근. M2는 유막과 조도의 상호작용을 하나의 공식으로 통합.

#### (7) 입력 복잡도와 계산 비용

| | M1 | M2 | M3 |
|---|---|---|---|
| 필수 입력 | ν₄₀, ν₁₀₀, α_pv, φ_s (4개) | + τ_Eyring, Z_Roelands, k_fluid, β_visc (8개) | M2와 동일 |
| 프리셋 | 불필요 | Mineral / PAO / Ester | 동일 |
| 계산 비용 | **1×** (기준) | ~2× | ~2× |

M2는 입력이 많지만 **프리셋**(Mineral/PAO/Ester)을 선택하면 자동 설정된다.

#### 종합: 왜 M2가 Recommended인가

```
M1: 빠르고 간단하지만...
  ✗ 거칠기 무시 → 유막 과대 예측 → 위험을 못 잡음
  ✗ Barus → 고압 부정확
  ✗ 마찰/발열 분석 불가
  → 용도: 초기 검토, ISO 표준 κ만 필요할 때

M2: M1의 모든 약점을 보완
  ✓ 거칠기 통합 → 혼합윤활에서 현실적
  ✓ Roelands → 고압 정확
  ✓ 완전 Eyring → 마찰/동력손실 분석 가능
  ✓ 물리 기반 기아보정 (사용자 입력과 병행, 보수적 선택)
  ✓ Flash 온도 → 소착 위험 평가
  → 용도: 설계 실무의 기본 도구 (Recommended)

M3: M2와 비슷한 정밀도이지만...
  ✗ 거칠기 미포함 (M2에 의존)
  ✗ TRB에서 M1 대비 2~7%만 차이 (4영역 블렌딩 이점 미미)
  ✓ 원형~선접촉 연속 처리 가능 (볼 베어링 확장)
  ✓ Van Zoelen Film Decay 논문의 원래 파이프라인
  → 용도: 논문 비교/검증, 향후 볼 베어링 지원 시
```

**한마디**: M2는 "실무에서 합리적 비용으로 얻을 수 있는 최선의 정확도"를 제공한다. M1은 너무 단순하고, M3는 TRB에서 M2 대비 이점이 없으며, HMEHL은 정확하지만 너무 느리다.

### 이미지 속 주요 용어

- **Barus**: 기름의 점도가 압력에 따라 지수적으로 증가하는 간단한 모델. `η = η₀·exp(α·p)`. 고압에서 과대 예측.
- **Roelands**: Barus보다 정확한 고압 점도 모델. GPa 수준에서 현실적.
- **Gupta φ_T**: 고속 시 기름의 전단 발열로 유막이 얇아지는 효과를 보정하는 계수. 속도만 고려.
- **Eyring**: 기름이 높은 전단력을 받으면 뉴턴 유체처럼 행동하지 않고 전단 박화(shear thinning)되는 모델. 마찰 계수 계산에 필수.
- **FBNS**: Fischer-Burmeister Newton Strategy. 유막 출구에서 기름이 음압을 견디지 못해 기포가 생기는 현상(캐비테이션)을 물리적으로 정확히 처리하는 수치 기법.
- **TEHL**: Thermal EHL. 접촉부 내 온도 분포까지 계산하는 확장 모델.
- **P(x), h(x), T(x)**: HMEHL만 제공하는 **위치별 분포** — 접촉 영역 내 모든 점에서의 압력, 유막 두께, 온도. 경험식 모델은 대표값(스칼라) 하나만 제공.

## 3. 이미지 #4: 계산 파이프라인 비교

### 이미지 구조

4개 모델이 **세로 열(Swimlane)**로 나란히 배치되어 있다. 위에서 아래로 읽으면 각 모델이 같은 입력에서 출발하여 어느 단계에서 갈라지는지 한눈에 보인다.

### 단계별 설명

#### 1단계: 입력 (공통)

```
ν₄₀  = 40°C에서의 동점도 [mm²/s]  ← 기름이 얼마나 끈끈한지
ν₁₀₀ = 100°C에서의 동점도          ← 온도 올라가면 얼마나 묽어지는지
α_pv = 압력-점도 계수 [1/GPa]       ← 압력 받으면 얼마나 더 끈끈해지는지
geometry = 롤러/궤도면 곡률, 치수
load = 접촉 하중 [N/mm]
```

이 입력들로 운전 온도에서의 **실제 점도 η₀**를 Walther 방정식으로 보간한다.

#### 2단계: 점도 모델 — 여기서 첫 분기

- **M1**: Barus 모델 사용 → 간단하지만 고압에서 부정확
- **M2/M3/HMEHL**: Roelands 모델 사용 → GPa 접촉압에서 정확

**왜 중요한가**: 베어링 접촉부 압력은 1~3 GPa. 이 압력에서 기름의 점도는 상온의 **수백만 배**로 올라간다. Barus는 이를 과대 예측하여 유막이 실제보다 두껍게 나온다.

#### 3단계: 유막 공식 — 핵심 차이점

| 모델 | 유막 공식 | 설명 |
|------|----------|------|
| M1 | D-H closed | `H = 3.06 × U⁰·⁶⁹ × G⁰·⁵⁶ × W⁻⁰·¹⁰`. 세 개의 무차원수(U, G, W)를 넣으면 유막 두께가 바로 나온다. |
| M2 | D-H + rc(σ̄) | 위 공식 결과에 `rc = 1 − 0.573·exp(−0.74·Λ_eff⁰·²¹)` 거칠기 보정을 곱한다. 거친 표면 → rc < 1 → 유막 감소. |
| M3 | 4-regime blend | 4가지 극한 해(IR, IE, RP, EP)를 블렌딩. 저속~고속, 저하중~고하중 전 범위를 하나의 공식으로 커버. |
| HMEHL | Reynolds PDE | 편미분 방정식을 256개 격자점에서 수치적으로 풀어 유막의 **공간 분포**를 직접 계산. |

**무차원 파라미터 U, G, W란?**

EHL 문제를 보편적으로 표현하기 위해 물리량을 조합한 무차원수:

- **U** (속도) = `η₀ × u_m / (E* × R_eq)` — 점성력 대 탄성력의 비. 빠르고 끈끈할수록 유막이 두껍다.
- **G** (재료) = `α × E*` — 기름이 압력에 얼마나 민감한지. 클수록 유막에 유리.
- **W** (하중) = `q / (E* × R_eq)` — 하중이 클수록 유막이 얇아진다.

#### 4단계: 조도(거칠기) 처리

- **M1, M3**: 없음. 유막을 매끈 표면 기준으로 계산한 뒤, 나중에 Λ 비에서 거칠기와 비교.
- **M2**: 유막 공식 자체에 거칠기 통합. 거칠기가 유막 형성을 방해하는 효과 반영.
- **HMEHL**: Patir-Cheng 유동 계수(flow factor)로 Reynolds 방정식에 거칠기 효과를 균질화(homogenization).

#### 5단계: 보정 — 열과 기아

**열보정 φ_T** (0.3~1.0):
고속 시 기름이 전단 발열로 온도가 올라가면 점도가 떨어져 유막이 얇아지는 효과.

- Basic (M1): Gupta 공식 — 속도만 고려
- Advanced (M2/M3): Murch-Wilson 공식 — 속도 + **SRR(슬라이딩 비)** 고려. 슬라이딩이 많으면 발열 증가 → φ_T 더 감소.
- HMEHL: 에너지 방정식을 직접 풀어 자기 일관적(self-consistent) 온도 분포 계산. 별도 보정 불필요.

**기아보정 φ_s** (0.3~1.0):
접촉 입구에 기름이 충분히 공급되지 않는 상태(기아, starvation). 특히 그리스 윤활에서 심각.

- Basic: 사용자가 직접 값을 입력 (Oil: 1.0, Grease: 0.5~0.8)
- Advanced: 속도 파라미터(n×d_pw)에서 물리 기반으로 자동 계산. 고속일수록 φ_s 감소.

#### 6단계: 출력

- **M1/M2/M3**: h_c (중심 유막 두께) 스칼라 값 하나
- **HMEHL**: P(x), h(x), T(x) — 접촉 영역 전체의 압력/유막/온도 분포

#### 7단계: 공유 후처리

어떤 모델을 쓰든 최종적으로:

```
Λ (lambda 비) → 윤활 영역 분류 → κ (점도 비) → a_ISO (수명 수정 계수)
```

이 부분은 이미지 #5에서 상세히 설명한다.

## 4. 이미지 #5: 유막→수명 알고리즘

### 전체 흐름 한눈에

```
h_eff (유막) → [Film Decay] → σ (조도) → Λ → 영역 분류
                                            ├→ κ → a_ISO → L_10m (수명)
                                            └→ S_λ (마이크로피팅)
```

### 단계별 상세

#### h_eff: 유효 유막 두께

이미지 #4의 파이프라인 결과물. 열보정과 기아보정이 적용된 최종 유막:

```
h_eff = h_min × φ_T × φ_s
```

#### Film Decay h(t): 그리스 유막 감쇠 (선택적)

**그리스 윤활 전용**. 이미지에서 보라색 점선 박스로 표시.

그리스는 오일과 달리 접촉부에 기름을 지속 공급하지 못한다. 시간이 지나면 접촉 영역 주변의 그리스가 밀려나고(channeling), 기유(base oil) 삼출(bleeding)로만 보충된다.

Van Zoelen (2012) 모델:
- 시간 t에 따라 유막이 **급격히 감소** (처음 수 시간 내)
- 보충률 R > 0이면 **평형 유막 h_eq**에 수렴 — 이 값이 실제 설계 유막
- R = 0이면 유막이 계속 감소 → 최악 조건

#### σ: 합성 표면 조도

두 접촉면의 거칠기를 합성한 값:

```
σ = √(Rq_롤러² + Rq_궤도면²)
```

- Rq = RMS 조도 (표면 높이의 제곱평균제곱근)
- 일반 연삭 베어링강: Rq ≈ 0.15~0.3 μm
- 초정밀(Superfinish): Rq < 0.1 μm

#### Λ (Lambda 비): 핵심 허브

```
Λ = h_min / σ
```

**유막 두께 대 표면 거칠기의 비**. 이것이 윤활 상태를 결정하는 핵심 지표.

| Λ 범위 | 윤활 영역 | 의미 | 이미지 색상 |
|--------|----------|------|-----------|
| **> 3** | Full EHL | 유막이 조도보다 3배 이상 두꺼움. 금속 접촉 없음. 이상적. | 🟢 초록 |
| **1~3** | Mixed | 유막과 조도가 비슷한 수준. 일부 봉우리가 접촉. | 🟡 노랑 |
| **< 1** | Boundary | 유막이 조도보다 얇음. 대부분 금속 직접 접촉. 위험. | 🔴 빨강 |

#### κ (Kappa): 점도 비 — 수명 계산의 입구

ISO 281 수명 계산에 필요한 파라미터. **두 가지 결정 방법**이 있다 (이미지에서 다이아몬드로 표시):

**방법 1: ViscosityRatio** (기본, 간단)
```
κ = ν_actual / ν_ref
```
- ν_actual = 운전 온도에서의 실제 점도
- ν_ref = ISO 281이 요구하는 기준 점도 (베어링 크기와 속도에서 결정)
- 유막 계산 결과를 사용하지 않음. 점도만으로 판단.

**방법 2: FilmThicknessRatio** (정밀)
```
κ = Λ^1.3
```
- 실제 유막 계산 결과(Λ)를 사용하므로 더 정확
- 단, M2 모델과 함께 쓰면 **조도가 이중 반영**되는 문제 (M2가 유막에 이미 조도 포함 → Λ에서 또 조도로 나눔)

#### a_ISO: 수명 수정 계수

ISO 281:2007의 핵심 수식:

```
a_ISO = f(κ, e_c, C_u/P)
```

- **κ**: 윤활 상태 (위에서 결정)
- **e_c**: 오염도 계수 (기름이 얼마나 깨끗한지)
- **C_u/P**: 피로 하중 한계 대 실제 하중의 비

κ가 크면(윤활 양호) → a_ISO 증가 → 수명 길어짐  
κ가 작으면(윤활 불량) → a_ISO ≈ 0.1 → 수명 급감

#### L_10m: 수정 수명

```
L_10m = a_1 × a_ISO × L_10
```

- L_10 = 기본 정격 수명 (하중에서만 결정)
- a_1 = 신뢰도 계수 (90% 신뢰도에서 1.0)
- a_ISO = 윤활/오염/재료 종합 수정 계수

**이것이 최종 베어링 수명 [백만 회전]**.

#### S_λ: 마이크로피팅 안전율 (사이드 브랜치)

이미지에서 Λ 노드에서 오른쪽으로 갈라지는 점선 분기:

```
S_λ = Λ_min / Λ_perm
```

- Λ_min = 가장 얇은 유막의 Λ
- Λ_perm = 허용 Λ (표면 처리 + 첨가제에 따라 결정)

| S_λ | 판정 | 의미 |
|-----|------|------|
| ≥ 2.0 | Safe 🟢 | 마이크로피팅 위험 없음 |
| 1.0~2.0 | Marginal 🟡 | 주의 필요 |
| < 1.0 | AtRisk 🔴 | 마이크로피팅 고위험 |

**마이크로피팅**: 표면에 수십 μm 크기의 미세 구덩이가 생기는 손상. Mixed/Boundary 윤활에서 조도 봉우리의 반복 접촉으로 발생. ISO 281의 **표면하 피로** 수명과는 별도로 평가해야 하는 **표면 기인 고장 모드**.

## 5. 이미지 #6: WEC 리스크 평가

### WEC란?

**WEC** = White Etching Crack (백색 식각 균열)

베어링 내부에서 발생하는 특수한 조기 파손 모드. 단면을 현미경으로 보면 균열 주변 조직이 **하얗게** 변해 있어서 이름이 붙었다. 수소 침투에 의한 조직 변태가 원인으로 추정되며, 설계 수명의 5~20%에서 갑자기 파손이 발생하여 매우 위험하다.

**WEC 발생 조건** (문헌 합의):
1. 높은 접촉 하중 하에서 슬라이딩(미끄러짐)이 동시 발생
2. 누적 마찰 에너지가 임계값 초과
3. 국부적 고온(스미어링) 발생

### 이미지 #6의 구조: 상단→중단→하단

#### 상단: TRB 기구학 (Kinematics)

WEC 평가의 입력 데이터를 생성하는 단계.

**Cone-apex 기하학**:
TRB의 핵심 기하학적 특성 — 내륜, 외륜, 롤러의 원추면이 모두 베어링 축 위의 **한 점(apex)**에서 만난다. 이 조건이 정확히 만족되면 순수 구름(슬라이딩 = 0)이 된다.

이 기하학에서 계산되는 것:
- **ω_cage**: 케이지(보지기) 회전 속도
- **ω_roller**: 롤러 자전 속도
- **u_slide**: 슬라이스별 슬라이딩 속도 (이상적 기하에서는 0)

**SRR** = Slide-Roll Ratio = u_slide / u_roll

롤러 표면 속도 대비 미끄러짐의 비. 순수 구름이면 0, 슬라이딩이 크면 0.05~0.15 수준.

**μ_eff**: Eyring 트랙션 모델로 계산한 유효 마찰 계수.

#### 중단: 3가지 독립 평가 기준

##### 기준 1: Guo Slip-under-Load (파란색)

Guo (2021) 논문 기반. **"높은 하중과 슬라이딩이 동시에 발생하는 빈도"**를 시계열로 추적.

- 시뮬레이션의 각 시간 스냅샷에서: 이 순간 하중이 높은가? + 이 순간 슬라이딩이 있는가?
- 둘 다 YES인 이벤트의 비율을 카운트
- `risk_index = 0.6 × slip_load_fraction + 0.4 × load_severity`

**직관**: 하중이 낮을 때 미끄러지면 큰 문제 없다. 하중이 높을 때 미끄러지면 표면에 큰 마찰 에너지가 투입되어 수소 생성 → WEC 위험.

##### 기준 2: 누적 마찰 에너지 (주황색)

Argonne 국립연구소 기반. **"총 마찰 에너지 밀도가 임계값을 초과하는가"**.

```
에너지 밀도 = Σ(μ × Q × u_slide × dt) / A_contact   [J/mm²]
```

- μ = 마찰 계수, Q = 접촉 하중, u_slide = 슬라이딩 속도, dt = 시간 간격
- A_contact = 접촉 면적
- **E_crit = 50 J/mm²**: 이 값을 초과하면 WEC 고위험

**직관**: 마찰 에너지는 접촉부에서 열과 화학 반응(수소 생성)을 유발한다. 누적량이 임계치를 넘으면 조직 변태 시작.

##### 기준 3: Smearing / Flash Temperature (빨간색)

순간적 고온 발생에 의한 표면 손상 평가.

- **Peak SRR**: 최대 슬라이딩 비. SRR > 0.05이면 주의, > 0.10이면 위험.
- **Negative SRR**: 롤러가 궤도면보다 **느리게** 구르는 상태. WEC 문헌에서 양의 SRR보다 **60% 더 엄격한** 임계값을 적용 (더 위험하다고 알려짐).
- **ΔT flash**: Blok 공식으로 계산한 순간 접촉 온도 상승. `ΔT = C × μ × Q × |V_slide|`. 150°C 이상이면 윤활유 열화 위험.

#### 하단: 종합 WEC 위험도

3가지 기준의 **worst-case**(가장 나쁜 결과)를 취하여 종합 판정:

| 레벨 | 의미 |
|------|------|
| **Low** 🟢 | WEC 위험 낮음 |
| **Medium** 🟡 | 주의 필요, 윤활/표면 처리 검토 |
| **High** 🟠 | 높은 위험, 설계 변경 권장 |
| **Critical** 🔴 | 매우 높은 위험, 즉시 대응 필요 |

## 7. 부록: Reynolds PDE 상세

### 7.1 개요

Reynolds 방정식은 **얇은 유체 막(thin film)** 내부의 압력 분포를 구하는 편미분방정식이다. 1886년 Osborne Reynolds가 Navier-Stokes 방정식을 **윤활 조건**에 맞게 단순화하여 유도했다.

본 프로젝트의 HMEHL 솔버(`src-tauri/src/solver/hmehl.rs`)가 이 방정식을 직접 수치적으로 풀어 접촉부 내 위치별 압력·유막·온도 분포를 구한다. 경험식(M1/M2/M3)이 스칼라 대표값 하나만 제공하는 데 비해, Reynolds PDE를 풀면 **출구 압력 스파이크, 유막 수축부, 캐비테이션 영역** 등 접촉부의 상세 물리를 포착할 수 있다.

### 7.2 Navier-Stokes → Reynolds 유도

3D 유체 운동을 기술하는 Navier-Stokes 방정식에 다음 **윤활 근사(lubrication approximation)** 가정을 적용하면 Reynolds 방정식이 된다:

| 가정 | 물리적 의미 |
|------|------------|
| 유막 두께 ≪ 접촉 길이 | h ~ 0.1 μm, 접촉 폭 b ~ 200 μm → h/b ~ 10⁻³ |
| 관성력 무시 (Re ≪ 1) | 점성력이 지배적 — 유체가 매우 느리고 얇은 막에 갇혀 있음 |
| 막 두께 방향 압력 일정 | ∂p/∂z ≈ 0 — 막이 너무 얇아서 두께 방향 압력 변화 무시 |
| 정상 상태 (또는 준정상) | 시간 변화가 충분히 느림 |

이 가정 하에 3차원 벡터 방정식이 **2차원 스칼라 방정식**으로 축소된다. 자유도가 극적으로 줄어들어 수치 해석이 실용적으로 가능해진다.

### 7.3 Reynolds 방정식의 형태

**2D(면접촉) 일반 형태:**

```
∂/∂x [ρh³/(12η) · ∂p/∂x] + ∂/∂y [ρh³/(12η) · ∂p/∂y] = ∂(ρhū)/∂x + ∂(ρh)/∂t
```

**1D(선접촉) 형태 — TRB 슬라이스에 적용:**

```
d/dx [ρh³/(12η) · dp/dx] = d(ρhū)/dx
        ↑                       ↑
   Poiseuille 항             Couette 항
   (압력 구동 유동)          (표면 끌림 유동)
```

TRB의 롤러-궤도면 접촉은 **선접촉(line contact)**이므로 주 유동 방향(x, 구름 방향)만 고려하면 1D로 충분하다.

**각 기호의 의미:**

| 기호 | 의미 | 단위 | 전형적 값 (TRB) |
|------|------|------|-----------------|
| x | 유동 방향 좌표 (롤러 구름 방향) | m | 접촉 폭 ~200 μm |
| p(x) | 유막 내 압력 분포 | Pa | 0 ~ 3 GPa |
| h(x) | 유막 두께 분포 | m | 0.05 ~ 1 μm |
| η(p) | 점도 (압력 의존) | Pa·s | η₀ ~ 0.01 → 접촉부에서 ×10⁶ |
| ρ(p) | 밀도 (압력 의존) | kg/m³ | ρ₀ ~ 850 → +20~30% |
| ū | 평균 표면 속도 = (u₁+u₂)/2 | m/s | 1 ~ 20 m/s |

### 7.4 좌변: Poiseuille 항 (압력 구동 유동)

```
d/dx [ε · dp/dx]     여기서 ε = ρh³/(12η)
```

압력 기울기(dp/dx)에 의해 유체가 높은 압력에서 낮은 압력으로 흐르는 항이다.

**핵심 특성 — h³ 의존성:**
- 유막이 2배 얇아지면 압력 유동은 **8배** 감소 → 극도로 비선형
- EHL 접촉 중심부에서는 Roelands 모델에 의해 η/η₀ ~ 10⁶ 이상으로 증가
- 따라서 ε = ρh³/(12η) → 0이 되어 **압력이 사실상 Hertz 분포에 고정**됨
- 이 영역에서는 유체가 "유리화(glassy state)"되어 거의 고체처럼 거동

```
접촉 중심부:  η → ∞  →  ε → 0  →  dp/dx 자유  →  p ≈ p_Hertz
접촉 입/출구: η ≈ η₀  →  ε 유한  →  Reynolds가 압력을 적극 결정
```

본 프로젝트에서는 Roelands 압력-점도 모델을 사용한다:

```
η(p) = η₀ · exp[S · (-1 + (1 + p/p_r)^Z)]
```

여기서 S ≈ 1.1, p_r = 196 MPa, Z는 Roelands 지수 (보통 0.6~0.8).

### 7.5 우변: Couette 항 (끌림 유동)

```
d(ρhū)/dx
```

두 표면(롤러와 궤도면)이 상대 운동하면서 유체를 접촉부로 **끌고 들어가는** 항이다.

- 이것이 유막을 형성하는 **원동력** — 속도가 0이면 유막이 생기지 않음
- 접촉부 입구(entry zone)에서 간극이 좁아지면서 유체가 압축됨 → 압력 발생
- 이 "쐐기 효과(wedge effect)"가 EHL 유막의 근본 메커니즘

```
입구 영역:
                 ╲                      유체 끌림 방향
  ───────────────── 궤도면 ──→ ū        ─────────→
       ╲           h 감소
        ╲         ↗ 유체가 압축됨
         ╲       ↗
  ─────── 롤러 ──→ ū
```

### 7.6 EHL 커플링 — 왜 풀기 어려운가

Reynolds 방정식 단독으로는 풀 수 없다. **세 가지 방정식이 서로 결합**되어 있다:

```
┌──────────────────────────────────────────────────┐
│                                                  │
│  ① Reynolds eq.     p(x) ←──→ h(x)              │
│       ↕                        ↕                 │
│  ② 탄성 변형        h(x) = h₀ + geometry         │
│                          + elastic_deformation   │
│       ↕                                          │
│  ③ 상태 방정식      η(p), ρ(p)                   │
│                                                  │
└──────────────────────────────────────────────────┘
```

1. **Reynolds → 압력 p(x)** 를 구하면
2. **탄성 변형**: 그 압력이 강철 표면을 변형시켜 **h(x)가 변함** (탄성 적분)
3. **상태 방정식**: 압력이 점도 η와 밀도 ρ를 변화시킴 (Roelands, Dowson-Higginson)
4. 변한 h, η, ρ를 다시 Reynolds에 넣으면 p가 변함

이 순환이 수렴할 때까지 **반복(iteration)**해야 한다. 문제는:

- **강한 비선형성**: h³과 exp(p) 의존성으로 작은 h 변화가 p를 크게 바꿈
- **스케일 차이**: 입구에서 ε ~ 10⁻⁶, 접촉 중심에서 ε ~ 10⁻²⁰ → 강성 행렬의 조건수 매우 나쁨
- **단순 반복은 발산**: 직접 대입(Picard) 반복은 대부분 발산

이 때문에 HMEHL 솔버에서 **FAS Multigrid + FBNS + 분배/선 완화(distributive/line relaxation)** 같은 고급 수치기법을 사용한다.

### 7.7 캐비테이션 (Cavitation) 처리

접촉부 출구에서 유막이 급격히 넓어지면 Reynolds 방정식이 **음수 압력**을 예측한다. 물리적으로 액체는 음압을 견딜 수 없으므로 **기포가 형성**(캐비테이션)되고 압력은 0으로 고정된다.

이를 수학적으로 처리하는 것이 **상보성 문제(complementarity problem)**:

```
p ≥ 0,  θ ≥ 0,  p · θ = 0
```

- **p > 0 영역 (full film)**: 유체가 간극을 완전히 채움, θ = 0
- **θ > 0 영역 (cavitated)**: 기포 존재, p = 0, θ는 기포 비율

본 프로젝트에서는 **FBNS (Fischer-Burmeister Newton-Schur)** 알고리즘으로 이를 처리한다. 핵심 아이디어:

```
FB(a, b) = √(a² + b²) − a − b = 0   ⟺   a ≥ 0, b ≥ 0, ab = 0
```

Fischer-Burmeister 함수를 사용하면 부등식 조건을 **매끄러운 방정식**으로 변환할 수 있어 Newton 반복에 직접 통합된다. 출구에서 음압이 나오면 θ로 흡수하여 질량 보존을 자동으로 만족시킨다.

### 7.8 무차원화

수치 안정성을 위해 Hertz 접촉 매개변수로 무차원화한다:

| 무차원 변수 | 정의 | 설명 |
|------------|------|------|
| X = x/b | b = Hertz 반폭 | 위치를 접촉 폭 단위로 |
| P = p/p_h | p_h = Hertz 최대 압력 | 압력을 접촉 압력 단위로 |
| H = h·Rₓ/b² | Rₓ = 등가 곡률 반경 | 유막을 기하학적 스케일로 |
| ρ̄ = ρ/ρ₀ | 밀도비 | 1 근처에서 변동 |
| η̄ = η/η₀ | 점도비 | 1 ~ 10⁶+ 범위 |

**무차원 Reynolds 방정식:**

```
d/dX [ε̄ · dP/dX] = d(ρ̄H)/dX

ε̄ = ρ̄H³/(η̄Λ)
```

여기서 Λ = 12η₀ūRₓ²/(b³p_h)는 무차원 속도 파라미터(Moes 수와 관련). 이 파라미터가 EHL 해의 성격을 결정한다.

### 7.9 전형적인 EHL 해 (결과 형태)

Reynolds PDE를 풀면 다음과 같은 특징적인 분포가 나타난다:

```
압력 p(x)                        유막 h(x)

   │        ╱╲ ← 출구 스파이크      │
   │       ╱  ╲                    │╲
   │  ╱───╱    ╲                   │ ╲____________╱╲ ← 출구 수축
   │ ╱  Hertz   ╲                  │    평탄 영역    ╲   (h_min)
   │╱    분포     ╲____            │____________________╲___
   └─────────────────→ x          └──────────────────────→ x
     입구        출구                입구              출구
```

**3가지 특징적 영역:**

| 영역 | 압력 특성 | 유막 특성 |
|------|----------|----------|
| **입구 (entry)** | 압력이 빌드업 — 유체가 좁아지는 간극으로 유입 | 급격히 감소 |
| **중심 (Hertz zone)** | p ≈ p_Hertz — η → ∞로 ε → 0이므로 압력이 고정 | 거의 평행 (평탄 영역) |
| **출구 (exit)** | **압력 스파이크** + 급강하 → 캐비테이션 | **유막 수축** → h_min 결정 |

**출구 압력 스파이크(secondary pressure spike):**
- 유막이 급격히 수축하면서 유체가 압축 → 국소 압력 피크 발생
- Hertz 최대 압력의 20~50% 추가 상승 가능
- 이 스파이크 아래에서 **표면하 전단 응력 집중** → 피로 수명에 영향
- 경험식(M1/M2/M3)으로는 포착 불가 → HMEHL만 예측 가능

**출구 유막 수축(constriction):**
- 압력 스파이크 직후 유막이 급격히 좁아지는 부분
- 여기서 **h_min (최소 유막 두께)**이 결정됨
- h_min ≠ h_c (중심 유막) — 보통 h_min ≈ 0.7 × h_c

### 7.10 거칠기 확장 (Average Reynolds Equation)

실제 베어링 표면은 매끈하지 않다 (Rq ≈ 0.15~0.3 μm). 유막 두께(~0.1~1 μm)와 비슷한 스케일이므로 거칠기가 유동에 직접 영향을 미친다.

Patir-Cheng (1978)의 **유동 계수(flow factor)** 접근:

```
d/dx [φ_x · ρh³/(12η) · dp/dx] = d(ρh(1−θ)ū)/dx
```

- **φ_x(Λ_local)**: 압력 유동 보정 계수
  - Λ_local = h/Rq (국소 유막/조도 비)
  - Λ_local > 3 → φ_x ≈ 1 (거칠기 영향 없음)
  - Λ_local < 1 → φ_x < 1 (거칠기가 압력 유동을 방해)

이 접근은 개별 조도 봉우리를 직접 해석하는 대신 **통계적 평균화(homogenization)**로 거칠기 효과를 반영한다. 계산 비용이 매끈 표면과 거의 같으면서도 혼합윤활 영역에서의 정확도를 크게 향상시킨다.

### 7.11 HMEHL 솔버의 수치 기법 요약

본 프로젝트의 HMEHL 솔버가 Reynolds PDE를 풀기 위해 사용하는 핵심 기법:

| 기법 | 역할 |
|------|------|
| **FAS Multigrid** | 다중 해상도 격자에서 반복 → 수렴 가속 (O(N)). 미세 격자의 고주파 오차를 조대 격자에서 저비용으로 해소 |
| **분배 완화 (Distributive relaxation)** | Venner (1991). ε → 0인 영역(접촉 중심)에서도 안정적인 완화. 기존 Gauss-Seidel이 발산하는 영역을 커버 |
| **선 완화 (Line relaxation)** | 한 행/열 전체를 삼중대각(tridiagonal) Newton으로 동시 풀이 → 분배 완화보다 빠른 수렴 |
| **FBNS** | 캐비테이션 상보성을 Newton 반복에 매끄럽게 통합 |
| **에너지 방정식 (TEHL)** | 유막 내 온도 분포를 별도 후처리 → 마찰/발열 평가에 활용 |

```
Multigrid V-cycle:
  미세 격자 (256pt) ──완화──→ 잔차 제한 ──→ 조대 격자 (128pt)
                                              ──완화──→ 잔차 제한 ──→ (64pt)
                                                                       ...
  미세 격자 ←── 보간 보정 ←──────────────── 조대 격자 ←── 보간 보정 ←── ...
```

이 과정을 3~10 V-cycle 반복하면 전체 격자에서 동시에 수렴이 이루어진다. 단일 격자 반복이 O(N²) 이상인 데 비해 Multigrid는 **O(N)** 복잡도를 달성한다.
