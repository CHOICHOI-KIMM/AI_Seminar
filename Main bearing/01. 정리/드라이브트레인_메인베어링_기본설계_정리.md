# 드라이브트레인 및 메인베어링 기본설계

> 기본설계 레포트 작성을 위한 설계조건 정의 재료 정리

---

## 1. 드라이브트레인 기본 형상 설계

### 설계조건 정의

#### 기능 정의
- 허브 연결 및 지지
- 기어박스 연결 및 동력 전달

#### 작동조건 / 경계조건 정의
- 6자유도 하중 (극한 / 등가피로 하중)
- 회전속도
- 싸이클
- 작동 온도
- 메인베어링 하중 지지

#### 소재 정의
- 소재 물성치 검토
- 제조성 검토

#### 열처리 조건 정의
- 기계적 물성치 / 열처리 깊이 등 검토
- 열처리 기법 검토

#### 성능 요구조건 정의
- 정적 강도
- 피로 수명
- 변형 강도
- 제조성
- 조립성
- 나셀 패키징

#### 성능 평가 기준 정의
| 평가 항목 | 평가 기준 |
| --- | --- |
| 정적강도 / 피로수명 평가 | DIN 743 |
| 변형량 평가 | Timoshenko beam |
| 응력집중 평가 | Analytic or FEM |
| 프레팅 평가 | Analytic or FEM |
| 무게 평가 | 3D CAD |

#### 설계변수 정의
- 형상 및 섹션
- 외경
- 두께
- 테이퍼
- 길이
- 모서리 필렛
- 형상 비율 (L/D, D/t 등)

#### 설계 제약조건 정의
- 제조성 고려 외경 / 두께 / 길이 조건
- 열처리 고려 외경 / 두께 / 길이 조건
- 성능 고려 형상 비율
- 메인베어링 조립 고려 외경 / 두께 조건

#### 조립조건 정의
- 허브 조립 공차 / 표면 처리
- 기어박스 조립 공차 / 표면 처리
- 베어링 조립 공차 / 표면 처리

---

## 2. 메인베어링 기본 형상 설계

### 설계조건 정의

#### 기능 정의
- 메인샤프트 지지
- 5자유도 복합 변동 풍하중 흡수

#### 작동조건 / 경계조건 정의
- 5자유도 하중 (극한 / 등가피로 하중)
- 회전속도
- 싸이클
- 작동 온도

#### 소재 정의
- 내외륜 / 롤러 소재 별도 검토
- 소재 물성치 검토
- 제조성 검토

#### 열처리 조건 정의
- 내외륜 / 롤러 열처리 별도 검토
- 기계적 물성치 / 열처리 깊이 등 검토
- 열처리 기법 검토

#### 윤활유 (그리스) 정의

**기유 점도 검토**
- 40, 100 동점도
- 작동영역 동점도
- 저온 작동성
- 고온 버팀성
- 흐름성
- VI
- 기타

**그리스 상세 물성 검토**
- 기유 종류: Mineral, Synthetic
- 증점제 종류: Ni, Ca 등
- 첨가제 종류: EP, AW, Viscosity Modifier 등
- 제조사: Fuchs, Shell, SKF 등

#### 성능 요구조건 정의

**정적 강도**
- 정적 안전율
- 최대 접촉응력
- 접촉패턴 양호

**피로 수명**
- 내부 기점 피로
- 표면 기점 피로

**윤활 성능**
- 최소 유막두께
- Lambda / Kappa ratio
- 혼합윤활 특성 (최대 압력, 고체 접촉 비율)
- 그리스 윤활 특성 (Starvation 특성, 유막두께)

**기타**
- 제조성
- 조립성
- 나셀 패키징

#### 성능 평가 기준 정의

**정적 강도**
| 평가 항목 | 평가 기준 |
| --- | --- |
| 정적 안전율 | ISO 76 |
| 최대 접촉응력 | ISO 17956, Analytic |
| 접촉패턴 | Analytic |

**피로 수명**
| 평가 항목 | 평가 기준 |
| --- | --- |
| 내부 기점 피로 | ISO 281 / 16281 |
| 표면 기점 피로 | SKF GBLM |

**윤활 성능**
| 평가 항목 | 평가 기준 |
| --- | --- |
| 유막두께 | ISO 281 |
| 혼합윤활 특성 | 수치해석 |
| 그리스 윤활 특성 | 경험식, 수치해석 |

**기타**
- 내륜 크립: Analytic or FEM

#### 설계변수 정의
- 베어링 종류: TRB × 2
- 배열 (F2F, B2B)
- L (베어링 간 거리)

**단일 베어링 설계변수**
- D
- d
- T
- B
- a
- Alpha
- Dpw
- Dwe
- Lwe
- Beta
- 형상 비율 (내외륜 / 롤러)
- 내외륜 / 롤러 프로파일
- 표면 거칠기 (내륜 / 외륜 / 롤러)
- 리브 형상
- 예압량

#### 설계 제약조건 정의
- 베어링 조립성 고려
- 제조성 고려
- 열처리 고려
- 성능 고려 형상 비율

#### 조립조건 정의
- 메인샤프트 조립 공차 / 표면 처리
- 하우징 조립 공차 / 표면 처리
