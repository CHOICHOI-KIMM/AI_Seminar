> 종합 분석하여, 풍력터빈용 설계보고서 **양식(템플릿)** 을 체계적으로 구축하기 위한 계획.

## 2. 두 시스템의 공학적 차이 (양식 결정의 근거)

| 측면 | 항공 엔진기어박스 (A) | 풍력 드라이브트레인·메인베어링 (B) |
|---|---|---|
| 기능 | HP rotor 동력 **인출·분배** | 허브 하중 **지지** + 동력 전달 |
| 핵심 부품 | 기어(베벨/헬리컬/평), 스플라인축(RDS) | **메인샤프트, 메인베어링(TRB×2)** |
| 지배 하중 | 회전수·토크 (임무 Load case) | **6-DOF/5-DOF 복합 변동 풍하중** (극한/등가피로) |
| 속도·크기 | 고속·소형·경량(Al 하우징) | 저속·대토크·대형·중량 |
| 수명 기준 | 비행시간(hr) | **20년+ 설계수명, 등가피로** |
| 환경 | 엔진 코어 고온 → 열관리 | 옥외 광역온도(저온 작동성·고온 버팀성) |
| 윤활 | 오일 jet (MIL-PRF-23699) | **그리스** (증점제·첨가제·starvation) |
| 소재 | 항공 기어강(Pyrowear 53, 9310, M50) | 베어링강 내·외륜/롤러 **별도 검토** |
| 대표 평가규격 | ISO 10300, AGMA 937, ISO 6336 (기어) | ISO 76, ISO 281/16281, ISO 17956, SKF GBLM |
| 공통 규격 | **DIN 743(축), ISO 76·16281(베어링)** — 양쪽 공유 |

## 3. 취사선택 매트릭스 (Keep / Adapt / Drop / Add)

### KEEP (A에서 그대로 계승)
- 문서 아키텍처: 개요 → 시스템 요구도 → 공통 설계기준 → 서브시스템별 설계 → 출처검증 부록
- 서브시스템 3분할: `구조 / 설계 요구조건 / 설계·해석 결과`
- 안전율·기준 표 형식, `[TBD]` 표기, **출처 검증 부록**
- DIN 743(축 강도), ISO 76(정적)·ISO 16281(피로) — 풍력에도 유효

### ADAPT (구조는 유지, 내용을 풍력으로 치환)
- 임무별 Load case(비행) → **DLC / 6-DOF 하중 스펙트럼 + 등가피로**
- 오일 jet 윤활 → **그리스 윤활**(기유점도·증점제·첨가제·starvation·Lambda/Kappa)
- 고온 열관리 → **옥외 광역온도 조건**
- 기어 중심 공통기준 → **베어링·샤프트 중심 공통기준**

### DROP (항공 특화 — 풍력 범위 밖)
- 베벨기어 기하제약(ISO 10300 / AGMA 937), 헬리컬·평기어 제약(ISO 6336)
- RDS 스플라인 fretting / 전단목(quill shaft) / ATS
- AGB 악세서리별 회전수·동력 분배
- (단, **기어박스와의 인터페이스**는 연결부로서 유지)

### ADD (풍력 특화 — A에 없음)
- 6-DOF/5-DOF 복합 변동 풍하중, 극한·등가피로, DLC 정의
- 그리스 상세 물성(기유 종류·증점제·첨가제·제조사)
- 베어링 내부 기하 설계변수(D, d, T, B, a, α, Dpw, Dwe, Lwe, β, 프로파일, 리브, 예압, 배열 F2F/B2B)
- 표면기점 피로(SKF GBLM), 혼합윤활, 유막두께 Lambda/Kappa, 내륜 크립
- 나셀 패키징, 제조성·조립성, 20년 설계수명

## 4. 제안 보고서 양식 골격 (초안)

```
표지 / 개정 이력 / 목차
1. 개요
   - 목적 · 범위(메인샤프트 + 메인베어링) · 대상 시스템 정의
2. 시스템 개요 및 요구도
   2.1 시스템 구성   (허브 → 메인샤프트 → 메인베어링 → 기어박스, 구성품별 소재표)
   2.2 작동·경계 조건 (6/5-DOF 하중[극한·등가피로], 회전속도, 사이클, 설계수명, 작동온도, DLC/하중 스펙트럼 — IEC 61400-1/-4 기준)
   2.3 인터페이스     (허브 결합, 기어박스 결합, 베어링-샤프트, 베어링-하우징)
3. 공통 설계기준
   3.1 소재 및 열처리 (샤프트 / 베어링 내외륜·롤러 별도)
   3.2 메인샤프트(축) — DIN 743
   3.3 메인베어링 — ISO 76(정적)·ISO 281/16281(피로)·ISO 17956(접촉응력)·SKF GBLM(표면기점)
   3.4 윤활(그리스) — 기유점도·증점제·첨가제·유막두께·starvation
   3.5 평가기준·안전율 종합표
4. 메인샤프트(드라이브트레인) 설계
   4.1 구조
   4.2 설계 요구조건 (설계변수: 외경/두께/테이퍼/길이/필렛/형상비율 · 제약조건 · 조립조건)
   4.3 설계 및 해석 결과 (정적강도 · 피로수명 · 변형량 · 응력집중 · 프레팅 · 무게)
5. 메인베어링 설계
   5.1 구조 (TRB×2, F2F/B2B 배열, 예압)
   5.2 설계 요구조건 (단일 베어링 설계변수 · 제약조건 · 조립조건)
   5.3 설계 및 해석 결과 (정적강도 · 피로수명 · 윤활성능 · 내륜크립 · 무게)
6. 통합 검토 (조립성 · 나셀 패키징 · 제조성)
부록 A. 출처 검증 (표준 원문 인용)
```

## 5. 단계별 실행 계획

| Phase | 내용 | 산출물 |
|---|---|---|
| 0 | **스코프·양식 확정** (범위, 기어박스 포함 여부, 부록 수준) | 확정된 골격 |
| 1 | 문서 골격 생성 + 표지·개정이력·개요·목차 | 보고서 skeleton md |
| 2 | 2장 시스템 요구도 — **하중조건(DOF/DLC)** 우선 정의 | 요구도 표 양식 |
| 3 | 3장 공통 설계기준 — 소재/열처리/축/베어링/윤활 + 안전율 표 (표준 인용) | 기준 표 세트 |
| 4 | 4장 메인샤프트 설계 섹션 (구조/요구조건/해석결과 양식) | 샤프트 섹션 |
| 5 | 5장 메인베어링 설계 섹션 (설계변수·해석항목 양식) | 베어링 섹션 |
| 6 | 6장 통합검토 + 부록 A 출처검증 골격 | 통합·부록 |
| 7 | 전체 `[TBD]` 정리, 상호참조·표번호 정합성 검토 | V0.1 양식 완성 |

> 원칙: 각 Phase마다 A의 해당 섹션을 참조하되, §2 차이표·§3 매트릭스에 근거해
> "이 항목이 풍력에 유효한가"를 점검하며 진행한다.

## 6. Phase 0 확정 사항 (2026-07-09)
- **범위**: **메인샤프트 + 메인베어링**으로 확정. 증속기(기어박스)는 인터페이스로만 다루고 내부 설계 제외 → 4장 샤프트 / 5장 베어링 2분할 유지, 기어 전용 장 미신설.
- **출처 검증 부록**: **유지**. A의 부록 A처럼 ISO 76/281/16281/17956, DIN 743, SKF GBLM 등 모든 기준을 표준 원문으로 역추적.
- **하중 정의 표준**: **IEC 61400-1/-4** 기준으로 6-DOF 하중·DLC·등가피로 정의 (§2.2).
