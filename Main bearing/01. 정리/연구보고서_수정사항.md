## 2. 종류별 분류

### 2.1 문서 형식·성격 전환
- 결과형(납품형) → 연구형(Trade Study 기반) 전환 [①]
- §5.3 Trade Study → 설계로 성격 변경 [⑤]

### 2.2 구조·순서 변경
- §5 순서: 소재·열처리 → 형상·단면 [②]
- §6: 형식 확정을 6.1에 통합, 소재·열처리 → 그리스 → 배열 순 [②]
- §4: 4.1 메인샤프트 / 4.2 메인베어링으로 분류, 각 부품 4단 분류(소재·열처리/설계 기준/설계 제약조건/조립조건) [④]

### 2.3 장·절 신설
- §6.6 매크로 제원 설계 (Trade Study) [④] *(신설 당시 §6.5, 이후 레이아웃 신설로 §6.6)*
- §5.4 공차/표면처리 설계 [⑤]
- §6.7 공차/표면처리 설계 [⑤] *(신설 당시 §6.6)*
- §6.5 레이아웃 설계 (Trade Study) — 베어링 위치 L_h1·L_12 [⑥]

### 2.4 명칭 변경
- §4 「평가 기준 및 방법」 → 「설계 기준 및 방법」 [④]
- 「내부기하·프로파일」 → 「마이크로 제원」 [④]
- §5.3 「형상·단면 구성」 → 「형상·단면 설계」 [⑤]

### 2.5 내용 추가·반영
- 설계 제약조건·조립조건 반영 (그림1·2 → §4.1.3/4.1.4, §4.2.3/4.2.4) [④]
- §5.3 그림1 설계변수(형상·섹션/외경/두께/테이퍼/길이/필렛/형상비율) 설계 [⑤]
- §6.5 윤활 성능 세부 고려(최소 유막두께/Λ·κ/혼합윤활/그리스 starvation, 그림2) [⑤]
- §5.4·§6.6 공차/표면처리 설계에 조립조건 충족·윤활 성능 고려 [⑤]

### 2.6 확정 사항
- 베어링 형식 = TRB×2 [①]
- 샤프트 형상·단면 = 중공+테이퍼 [⑤]

### 2.7 작업 방식·파일 관리
- 별도 주문 없으면 md 파일 생성 금지 [③]
- `연구보고서_전환계획.md` 삭제 [③]
- Word(docx) 마스터 전환 — 양식 md는 단방향 소스, 역변환 금지 [⑦]
- V0.2 → V1.0 승격 (파일명·개정이력) [⑧]
