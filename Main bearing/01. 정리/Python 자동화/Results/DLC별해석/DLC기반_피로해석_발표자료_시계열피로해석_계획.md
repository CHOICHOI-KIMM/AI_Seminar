## 2. 발표에 쓸 핵심 재료

### 2-1. 입력과 규모

| 항목 | 값 | 출처 |
|---|---|---|
| 하중 자료 | GH Bladed 시계열 `.$150` · **111 DLC** | 프로세스 §3 |
| 30년 총 가동시간 | **263,014 h** (ScaleFactor × 시계열 길이 합) | DLC별해석 §5-3.0 |
| DLC당 시계열 점수 | 6,001 / 3,001 / 2,001 / 601점 | 〃 |
| 좌표 변환 | `FX = −Fz · FY = +Fy · AX = +Fx · MX = −Mz · MY = +My` · **축토크는 Input Power Load 로 별도 인가** | 프로세스 §4·§6 |
| 해석 | MASTA · **ISO/TS 16281** 점별 반복 → 외부 Miner 합산 | 프로세스 §8·§10 |

### 2-2. 문제 — 참값은 너무 비싸다

| 방식 | 규모 | 소요 |
|---|---|---|
| **참값 (dt = 0.1 s)** | 전 111 DLC 점별 ≈ **66.6만 해석** | **≈ 31시간** |
| 대표 DLC 1건 참값 | 6,001점 | 약 **19~22분** |
| **조합 (dt, k 빈 압축)** | 총 **9,150빈** | DLC당 **5 ~ 166초** |

→ 전수 참값은 설계 반복(사이징 최적화)에 쓸 수 없다. **정확도를 지키면서 비용을 두 자릿수 이상 줄이는 압축**이 필요하다.

### 2-3. 방법 — (dt, k) 스크리닝과 중앙 타겟팅

| 요소 | 내용 |
|---|---|
| 1단계 스크리닝 | **핀지지 강체정역학**으로 전 111 DLC 의 ε(k, dt) 맵을 **수 초**에 산출 (부록 1) |
| 이산화 `dt` | 시계열을 dt 간격으로 재표본 → 대표 빈으로 압축 (dt = 20 / 10 / 4 / 2 / 1 s) |
| 빈 압축 계수 `k` | 빈 대표하중 = 평균 + k·표준편차 — **k ∝ 변동계수(CV)** |
| 선정 기준 | **UW ∧ Sys 동시** ε 예측이 **0 ~ +3%** (보수측) 창 안에 들도록 **중앙 타겟팅** |
| 확정 분포 | dt=20 **69개** · 10 **13** · 4 **20** · 2 **7** · 1 **2** · 총 **9,150빈** |
| 불합격 시 | **k 보정 최대 3회** (dt 보존 우선) — 실제 보정 발생 **29건** |
| 판정 | 참값(dt=0.1) 대비 실측 ε_UW ∧ ε_Sys 가 0 ~ +3% 이면 합격 |

### 2-4. 결과 — 전 111 DLC 본해석

| 지표 | 값 |
|---|---:|
| 진행 | **111 / 111 완료** |
| 판정 | **합격 95 · 불합격 16** (보정 적용 29건) |
| ΣD30_UW (참값 기준) | **6.750** |
| ΣD30_DW | 1.245 |
| **수명 UW** | **4.44 yr** |
| 수명 DW | 24.10 yr |
| **수명 Sys** | **3.93 yr** |
| 조합 합산 검증 | ΣD30_UW 6.918 → 참값 대비 **+2.49% (보수측)** |
| 예측 정확도 | 평균 **0.77 %p** · 최대 6.16 %p |

**손상 커버리지** — 상위 16 DLC 가 손상의 51.6% (가동시간 37.8%), 상위 35개가 90.8%, 41개가 95.2%.
→ 손상은 소수 DLC(주로 `DLC1.2` 정상운전 고풍속 구간)에 집중된다.

### 2-5. 발표 가치가 큰 메시지 4가지

| # | 메시지 | 근거 |
|--:|---|---|
| **M1** | **31시간 → 수십 분**. 스크리닝 + 빈 압축으로 전 함대 피로해석을 설계 반복 안에 넣었다 | §2-2 · §2-3 |
| **M2** | **압축의 오차는 통제된 보수측이다** — 전체 편향 +2.49%, 예측 정확도 평균 0.77 %p | §5-4 · 부록 3·4 |
| **M3** | **손상은 소수 DLC에 집중** — 상위 16개가 절반, 35개가 90% | §5-3.0 |
| **M4** | **현 설계는 30년을 못 넘긴다 (Sys 3.93 yr)** → 다음 파트(사이징 최적화)의 출발점 | §5-4 |

### 2-6. 발표에서 **뺄 것**

| 제외 대상 | 사유 |
|---|---|
| 음수 rpm rev 부호 결함 발견·재스크리닝 경위 | 내부 시행착오. 결과에만 반영 |
| dt 수렴 스윕(부록 F)·데미지 계산 방법 비교(부록 C) | 방법 확정 과정. 결론만 사용 |
| 부록 2 (dt,k)\* 의 설계 의존성 연구 | 사이징 최적화 파트와 겹침 — 그쪽에서 다룸 |
| 부록 6 LDD 등가하중 비교 | 대안 방법 검토. 시간 여유가 있을 때만 |
| 유연체 샤프트·프리로드 모델 비교(부록 D·5) | 모델 선택 근거. 발표 범위 밖 |
| **불합격 16건의 개별 사유** | 표로 나열하지 않고, "저손상 DLC 에 집중되어 함대 수명 영향은 미미"로 정리 |

> **불합격 16건을 어떻게 말할 것인가** — 대부분 `DLC1.2-f/h/k` 등 **D30 ≤ 0.08 의 저손상 DLC**다. 판정창(0~+3%)을 벗어났을 뿐 절대 기여가 작아 함대 수명에 미치는 영향이 제한적이라는 점을, **커버리지 곡선 위에 불합격 DLC 를 표시**해 시각적으로 보이는 방식을 권장한다.

## 3. 구성안 2개 비교

### 안 A — 「비용 문제 해결」 서사 (6장) · **추천**

| 장 | 제목 | 핵심 메시지 | 그림 |
|--:|---|---|---|
| 1 | 문제와 대상 | 111 DLC · 263,014 h · 30년 수명을 판정해야 한다 | 입력 규모 KPI + DLC 구성 |
| 2 | 해석 체계 | 시계열 → 좌표변환 → MASTA(ISO/TS 16281) → Miner | **파이프라인 도해** |
| 3 | 비용의 벽 | 참값 전수 = 31시간 · 설계 반복에 쓸 수 없다 | 비용 비교 막대 |
| 4 | 압축 방법 | (dt, k) 스크리닝 + 중앙 타겟팅으로 0~+3% 창 안에 | **빈 압축 개념도 + dt·k 분포** |
| 5 | 검증 | 합격 95/111 · 편향 +2.49% 보수측 · 정확도 0.77 %p | **ε 산점도(예측 vs 실측)** |
| 6 | 함대 수명 | Sys 3.93 yr — 손상은 소수 DLC에 집중 | **DLC별 기여 + 커버리지 곡선** |

- **장점**: "비싸다 → 줄였다 → 맞는지 확인했다 → 답은 이렇다"로 기승전결이 명확. 방법 3 : 결과 3 배분.
- **단점**: 함대 결과가 마지막 한 장에 몰린다.

### 안 B — 「결과 선행」형 (7장)

1 문제 → 2 **결론 먼저**(Sys 3.93 yr · 30년 미달) → 3 해석 체계 → 4 비용의 벽 → 5 압축 방법 → 6 검증 → 7 손상 구조와 다음 파트 연결

- **장점**: 앞의 파트에서 시간이 밀려도 핵심 결론이 먼저 전달된다. 청중이 결과를 알고 방법을 듣는다.
- **단점**: 7장이라 시간 압박, 2장과 7장에 결과가 나뉘어 중복감이 생길 수 있다.

**권장**: **안 A**. 다만 1장 하단에 "결론 미리보기" 한 줄(Sys 3.93 yr)을 넣어 안 B 의 장점을 흡수한다.
