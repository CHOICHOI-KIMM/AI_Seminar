## 2. 발표에 쓸 핵심 재료 (원문에서 추출)

### 2-1. 문제와 판정기준

| 항목 | 값 | 출처 |
|---|---|---|
| 문제 | 현 26 MW급 메인베어링 사양이 **30년 피로수명 미달** | §1 |
| 제약 1 — 극한 강도 | Max Element Normal Stress **< 2,100 MPa** (극한 16 LC 전부) | §1 |
| 제약 2 — 피로 수명 | 30년 누적손상 **D30 ≤ 0.5** (UW·Sys 둘 다, 111 DLC) | §1 |
| D30 ≤ 0.5 의 의미 | 명목수명 60년 = L10 기준 손상 안전율 2 | §1 |

### 2-2. 기준선 (baseline)과 필요 개선 배수

| 지표 | 기준선 실측 | 목표 | 필요 개선 |
|---|---:|---:|---:|
| 극한 σ_max | **3,424.2 MPa** | < 2,100 | **1.63배 저감** |
| 피로 ΣD30_UW | **6.9739** | ≤ 0.5 | **14.0배 저감** |
| 수명 Sys | 3.85 yr | ≥ 60 yr | 15.6배 |
| 질량 (베어링 2 + 샤프트) | 54.4 t | — | (목적함수) |

### 2-3. 방법 — 응력 선행 3단계

| 근거 | 값 |
|---|---|
| **비용 비대칭** | 극한 응력 16 LC ≈ 7~20 s vs 피로 111 DLC ≈ 360 s → **응력이 20~40배 싸다** |
| P1 | 극한 응력 **전수 격자** (대리모델 없음) — 가능영역 직접 확정 |
| P2 | P1 통과점 대상 111 DLC 피로 검증 |
| P3 | 파레토 후보 5~10점 전량 재검증 (미착수) |
| 자유변수 6개 | `D_pw`, `α`, `D_we`, `L_we`, `z1`, `z2` — 나머지는 PCD 기준 종속화 |
| 무인 자동화 | MASTA(mastapy)로 제원 주입·베어링 재장착·샤프트 단면 재구성까지 스크립트화, **점당 0.30 s** |

### 2-4. 결과

| 단계 | 규모 | 소요 | 결과 |
|---|---|---:|---|
| P1 Phase 2 | 5,625점 전수 | 27.8분 | 가능해 **700건 (12.4%)** · 최경량 121.5 t |
| P1 Phase 3 (배치 확대) | 8,700점 전수 | 35분 | 가능해 **771건 (8.9%)** · σ 최소 **1,722.8 MPa** · 최경량 135.3 t |
| P2 Phase 1 | 12건 + 기준선 | 48.9분 | **12건 전원 합격**, 파이프라인 재현 오차 **0.7%** |
| P2 Phase 2 | 24건 (A·B) | 112.4분 | **24건 전원 합격**, 한계 대비 **4.7 ~ 11.3배 여유** |

**대표 설계안 (A5)** — σ 2,090.4 MPa · ΣD30_UW 0.0444 · life_Sys 653.8 yr · 질량 137.0 t
(`D_pw` 3,900 · α 27° · `D_we` 230 · `L_we` 550 · z1 1.0 · z2 4.0 · Z 49)

### 2-5. 발표 가치가 큰 발견 4가지

| # | 발견 | 근거 |
|--:|---|---|
| **F1** | **두 제약의 지배변수가 다르다** — 응력은 `L_we`(가능률 0 → 46.9%), 피로는 `D_we`(손상 −22~−26%, 통제 7쌍) | §8-2.5.3 · §8-5.6.3 |
| **F2** | **세장비 제약 `L_we/D_we ∈ [1.5, 2.5]` 가 두 변수를 묶는다** → 독립 확대가 불가능하고, 둘을 함께 키우는 것만이 유일한 경로. 이것이 최경량이 121.5 t 아래로 내려가지 못하는 **구조적 이유** | §8-3.6.4 |
| **F3** | **병목은 피로가 아니라 응력·질량이다** — 응력을 만족시키는 순간 피로가 4~12배 여유로 통과. 필요 배수 1.63 vs 14.0 이라는 사전 예상과 반대 결과 | §6-2 · §8-3.6.5 |
| **F4** | **`L_eff`(유효 스팬)는 지배적이나 충분하지 않다** — `L_eff` 가 동일(5.639 m)한 두 설계의 손상이 **+24.6%** 차이. 접촉각 α 는 스팬 의존으로 **부호가 뒤집힌다**(−7.8 ~ +4.9%) | §8-5.6.2 · §8-5.6.4 |

### 2-6. 발표에서 **뺄 것** (시행착오·내부 경위)

| 제외 대상 | 사유 |
|---|---|
| R5·R6 규칙 개정과 P1 Phase 1 무효화 | 내부 시행착오. 결과만 쓰면 충분 |
| σ=0 실패 36.9% → 0% 진단 경위 | 자동화 신뢰성 근거로 한 줄만 쓰거나 생략 |
| §6-3·§6-4 철회(ISO 281 카탈로그식 오적용) | 방법론 반성. 필요 시 "ISO/TS 16281 에서는 배수 환산이 성립하지 않는다" 한 문장으로 압축 |
| 부록 3 핀지지 힘평형 대조, 부록 4 T 자동갱신 경로 의존 | 검증 세부. 발표 범위 밖 |
| 부록 5 윤활조건(κ·λ·a_ISO)·빈 대표화 검증 | **별도 파트**. 이 6~7장에는 넣지 않음(단, 앞 파트에서 다룰 경우 연결만) |
| Phase 2 → Phase 3 질량 후퇴(121.5 → 135.3 t) | 배치 격자 변경에 따른 것. 발표에서는 **Phase 3 기준으로 일관되게** 서술해 혼선 제거 |

> **수치 일관성 원칙** — 발표자료는 **P1 Phase 3 + P2 Phase 2** 를 정본으로 삼는다. Phase 2 의 121.5 t 는 쓰지 않는다(`z1 ≥ 1.0` 배치 제한을 반영한 Phase 3 이 최신 판단이므로).

- **단점**: 피로해석(P2) 결과가 5·6장에 압축되어 "111 DLC 전수 피로검증" 의 무게가 덜 드러난다.

| 장 | 제목 | 핵심 메시지 |
|--:|---|---|
| 1 | 문제·판정기준 | 두 제약, 필요 개선 1.63배 / 14.0배 |
| 2 | 설계변수와 종속 사슬 | PCD 기준 종속화 — 6변수로 축약한 방법 |
| 3 | 전수 탐색 (P1) | 8,700점 · 771건 가능해 |
| 4 | 발견 1 — 응력의 지배변수 | `L_we` 가능률 0 → 46.9%, `D_pw`·`D_we` 하한은 통째로 배제 |

- **단점**: 7장이라 시간 압박. 발견이 3개로 나뉘어 한 문장 결론이 약해질 수 있다.

### 안 C — 「방법론 쇼케이스」형 (7장) · 미구현 (참고용)

1 문제 → 2 무인 자동화 파이프라인(MASTA·mastapy) → 3 비용 구조와 응력 선행 전략 → 4 전수 격자 설계 → 5 결과 요약 → 6 검증(재현 오차 0.7%·warn 0건) → 7 한계·향후

- **장점**: 자동화·해석 인프라 기여도를 주장하기 좋다. 실행 실적(0.30 s/점, 8,700점 35분)이 강한 소구점.
- **단점**: 사용자가 정한 **방법 2 : 결과 4** 배분과 어긋난다(방법 4 : 결과 3에 가까움).

**권장**: **안 A 를 뼈대**로 하고, 5장에 안 B 의 발견 3(α 부호 반전)을 한 줄 추가하는 형태.
현재 두 안이 모두 구현되어 있으므로, 대시보드에서 **A · B 키로 직접 비교한 뒤** 확정하면 된다.

막대 4종(σ · D30 · 수명 · 질량), 비율에 로그 스케일 적용. 안 A 6장 · 안 B 7장 KPI 에 사용.

### 안 B 전용 신규 차트 3종 (260802 추가)

| 차트 | 쓰는 곳 | 내용 | 데이터 |
|---|---|---|---|
| **`chain`** | 안 B 2장 | 종속 사슬 도해 — 자유변수 6 → 1~4단계 → MASTA 위임 | §4-3 종속식 (하드코딩) |
