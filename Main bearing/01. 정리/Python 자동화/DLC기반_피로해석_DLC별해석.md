## 4. 2단계 MASTA 검증 계획 (확정, 260723)

**판정 기준**: 손상 편향 ε ∈ [0, +3%] (보수측+3%이내). **UW ∧ Sys 동시 합격 = 합격. DW는 미고려(병기만)**.
기록 양식: **부록 9 §9-7 그대로** — DLC별 4표 (a: UW / b: DW / c: Sys 수명·ε / d: 해석시간, 빈수 열 포함).

### 4-1. (dt, k) 선정·검증 정책 스택 (260723 개정 — 승인)

**[선정]** (전 DLC, 스크리닝 맵 기반 · MASTA 불필요)
1. **연속 k + 중앙 타겟팅**: k를 그리드(0.05) 선형보간으로 연속화하고, 큰 dt 우선으로
   UW·Sys ∈ [0,3] 창 안에서 **ε_Sys가 목표 1.5%(창 중앙)에 최근접하는 k** 선택
   — min-k 선정이 Sys 하한 경계에 붙는 구조적 타이트함을 제거 (여유 ≥0.5%p 확보가 원칙)
2. **여유 <0.5%p(창 협소)면 dt 한 단계 축소** 후 재선정 — 보정 횟수 증가로는 창이 넓어지지 않으므로
   dt 축소가 구조적 해법
3. k 그리드 상한 3.0 (극저속 DLC6.4-a 계열의 k>1.5 수요 대응)
4. 적용 결과: **전 111 DLC ε_Sys 여유 ≥0.53%p** · dt=20 69개 유지 · 조합 배치 규모 9,150빈

**[검증·보정]** (참값 확보 DLC)
5. MASTA 실측 ε_UW·ε_Sys ∈ [0,3] 이면 확정
6. 불합격 시 **k 보정 최대 3회** (기존 1회→3회 완화, dt 보존 우선): 스크리닝 ε(k) 국소 기울기로
   `k′ = k + (1.5 − ε_실측)/기울기` → 해당 DLC만 재해석(회당 수 초~수십 초, 선형성으로 1회 수렴 기대)
7. 3회 실패 시에만 dt 축소
8. 전 DLC에서 |실측−예측| 기록 — 방법론 신뢰도 갱신

**[참값 방침]** (260723 확정)
9. **본격 배치 시 참값(dt=0.1 점별 MASTA)을 최우선으로 전 DLC 확보** — 이로써 ⑥의 보정 루프가
   전 DLC에 적용 가능해지고, 함대 합산은 참값 기반 정확값 사용

**표본 3 (DLC6.4-a-s3) 저속 κ클립·a_ISO 사전 검토** (MASTA 프로브 4점, 260723)

1. **κ 클립 실측**: 이론 κ(식 27+28) = 0.005~0.058 (전 점 유효범위 밖) → **MASTA는 전부 κ=0.1000으로 클립**
   — ISO 281 §9.3.4 하한("κ<0.1 계산 불가") 그대로. ν₁ 자체는 이론식과 0.1% 내 일치
2. **음수 rpm 처리**: MASTA는 ν₁에 **|n|** 사용 실측 확인 (rpm=−0.023 → ν₁=17,652 ≒ 이론 17,668)
3. **a_ISO = 0.1000 고정 (하중 무관)**: 저κ 구간 계수가 κ=0.1에서 κ항이 **정확히 0**이 되도록
   캘리브레이션됨 (1.5859−1.3993/0.1^0.054381 = −0.00006) → a_ISO = 0.1·1^(−9.185) = 0.1.
   의미: 심각한 경계윤활의 수명 페널티 바닥 = **기본수명의 10%**, 그 이하 외삽은 표준이 거부
4. **함의**: 스크리닝의 κ=0.1 클립 처리가 MASTA 내부 동작과 **구조적으로 동일** → κ클립 45개 DLC의
   예측 정합성 확보. 극저속 DLC는 수정수명 = 0.1×기본수명으로 단순화되어 κ 불확실성이 결과에 미포함

# 부록 2. 베어링 설계 변화에 따른 피로수명 해석 조건 변화 (연구·검토 방안)

## 2-1. 문제 정의

- 현 상태: **현행 설계(MASTA 모델 1개)에 대해서만** 전 111 DLC의 최적 (dt, k) 조합이 확보됨
- 고민 1 — **이식성**: 샤프트·베어링 설계 변경 시 최적 (dt, k)가 얼마나 변하는지 민감도 미확인.
  특정 모델에서 구한 조합을 다른 모델에 그대로 쓰는 것은 근거 없음
- 고민 2 — **재산출 비용**: 설계안마다 1단계 스크리닝 + 참값 전량(≈35h) + 최적화 반복은
  최적 설계 탐색(수십~수백 설계점)에서 감당 불가
- 고민 3 — **현실적 대안의 신뢰도**: 강체정역학 스크리닝으로 (dt, k)를 재산출해 쓰는 방안이 유력하나
  ① 그대로 쓸지 ② 보정할지 ③ 보정 기준을 참값 dt=0.1 대신 dt=1 수준으로 타협할지 미정

## 2-2. 쟁점의 체계화 — "(dt, k)\*는 무엇의 함수인가"

| 결정 요인 | 소속 | 설계 변경 시 | 근거 |
|---|---|---|---|
| 하중 시계열의 CV·스펙트럼 (빈 내 변동) | **DLC(바람) 속성** | **불변** | 허브 하중은 설계와 무관 |
| k\* ∝ CV 관계 (Jensen 편향 상쇄) | 방법론 속성 | 불변 | 부록 9 (k\* ≈ 1.17·CV) |
| 손상 지수 p=10/3, 편향의 곡률 구조 | 규격 속성 | 불변 | ISO 281 |
| 하중→P 사상 (기하 L·a·b, 축분배 Y1·e) | **설계 속성** | **변함** | §3-3.3 |
| a_ISO 곡률 (Cu/C 비, κ) | 설계+윤활 속성 | 변함 | 식 34~36 |
| UW/DW 수명비 → Sys 판정 창 위치 | 설계 속성 | 변함 | §9-7c |

**핵심 관찰 (이미 확보된 최강 증거)**: 핀지지 강체 모델은 FE 유연체 모델과 반력 +13~45%,
절대손상 3×가 다른 — 사실상 "극단적으로 다른 설계"임에도 **ε(k, dt) 예측은 0.0~0.6%p 일치** (부록 1).
실제 설계 변경(스팬 수%, C 수십%)은 핀지지↔FE 간극보다 훨씬 작은 섭동이므로,
**ε 맵과 (dt, k)\*는 설계에 둔감하다는 가설이 유력**하다.

## 2-3. 가설

- **H1 (주가설)**: (dt, k)\*는 1차적으로 DLC(하중 CV)의 함수이고 설계에는 2차적으로만 의존
  → 설계 변경 후에도 기존 (dt, k)\*가 ε ∈ [0, 3] 창 안에 남을 가능성이 높음
- **H2 (민감 요소 한정)**: 설계 의존이 나타난다면 다음 경로일 것
  - (a) 접촉각·Y1·e 변경 → 축력 분배 전환점 이동 → P의 하중 응답 기울기 변화
  - (b) Cu/C 비 변화 → a_ISO 곡률 변화 → 편향 크기 변화 (κ 동일해도)
  - (c) UW/DW 수명비 변화 → ε_Sys 가중이 바뀌어 **판정 창 위치**가 이동 (ε 자체보다 민감할 수 있음)
  - (d) 저속·κ클립 DLC: κ=0.1 바닥에 걸리면 오히려 설계 무관(a_ISO=0.1 고정)
- **H3 (여유 완충)**: 현 선정 정책(중앙 타겟팅, 여유 ≥0.5%p)이 설계 섭동의 완충 역할
  → "여유폭 > 설계 변경에 의한 ε 이동량"이면 재산출 불필요

## 2-4. 연구·검토 방안 — 3단계

### Phase A. 해석적 민감도 맵 (MASTA 불필요, 설계점당 ~10초)

- 스크리닝 경로의 설계 상수를 섭동하는 DOE 수행 — **변수·범위 확정 (260723 승인)**:

| 섭동 변수 | 확정 그리드 (굵게 = 현행) | 대변하는 설계 변경 |
|---|---|---|
| **Z1** (하중점→UW 거리) | 0.3 / 0.4 / 0.45 / **0.5** / 0.55 / 0.6 / 0.8 m | 베어링 배치 — UW 위치 |

- 미세점(Z1 ±0.05, L ±0.125)으로 국소 기울기(민감도), 경계점(0.3/0.8, 2.0/3.5)으로 허용역 한계 확인
- (베어링 내부제원 Y1·e·C·Cu 섭동은 후속 확장 항목으로 보류 — 현 단계는 배치 변수 우선)

- 각 설계점에서 전 111 DLC의 k\* 재산출(초 단위) → 산출물:
  ① Δk\*(설계변수) 민감도 순위 ② **기존 (dt,k)\* 유지 시 ε가 [0,3]을 벗어나는 섭동 크기 = 허용역(design margin)**
- 판정 지표: "ε 이동량 / 여유폭(0.5~1.5%p)" — 1 미만이면 해당 설계 변경엔 재산출 불필요

### Phase B. MASTA 스팟 검증 (설계 변형판 2~3개 × 대표 DLC 4~6개)

- 실제 MASTA 모델을 변형(예: 스팬 변경판, 베어링 용량 변경판, 샤프트 강성 변경판)
- 각 변형판에서 대표 DLC(고CV·저CV·저속·d빈·e빈 등 유형별)만:
  준참값(dt=1, 601점 ≈1.9분/DLC) + 기존 (dt,k)\* 조합 해석 → ε 실측
- Phase A의 해석적 예측 Δε와 대조 → **스크리닝 섭동 모델의 예측력 자체를 검증**
  (부록 1의 "비율 상쇄" 논리가 설계 섭동에도 성립하는지 직접 확인)

### Phase C. 운영 정책 확정 (설계 반복 루프용)

- 확정 목표 — 설계 변경 시 표준 절차(안):
  1. 스크리닝 상수만 갱신 → 전 DLC k\* 재선정 (수 분, MASTA 불필요)
  2. 대표 DLC n개만 MASTA 스팟 체크 (준참값 dt=1 기준, ~10분)
  3. 통과(ε ∈ [0,3]) 시 전체 적용 / 실패 시 해당 유형만 k 보정 (§4-1 ⑥ 준용)
  4. **참값 dt=0.1 전량은 최종 확정 설계 1회만** 수행
- 최적 설계 루프 비용: 설계 후보당 "수 분 + 스팟 10분" 수준으로 압축 (전량 35h 대비 ~1/100)

## 2-5. 준참값(dt=1) 타협의 근거와 확인 항목

- 취지: 설계 반복 중 비교 기준을 dt=0.1(6001점, ≈19분/DLC)에서 dt=1(601점, ≈1.9분/DLC)로 완화
- **선행 확인 필요**: 부록 6·8의 dt 수렴 실측에서 dt=1의 참값 대비 편차를 재확인하고,
  그 편차가 판정 여유(0.5~1.5%p) 대비 무시 가능함을 수치로 못 박은 후 채택
- 적용 원칙(안): 설계 **간 상대 비교**에는 dt=1 준참값 사용(편차가 설계 간 공통으로 상쇄),
  **절대 수명 보고**는 최종 설계의 dt=0.1 참값만 사용

## 2-6. 산출물·성공 기준

- 산출물: ① 설계변수별 민감도 맵(표·그래프) ② (dt,k)\* 허용역 표 ③ 설계 변경 표준 절차서(§C)
  ④ 준참값 dt=1 타당성 수치 근거
