## 4. 2단계 MASTA 검증 계획 (확정, 260723)

**판정 기준**: 손상 편향 ε ∈ [0, +3%] (보수측+3%이내). **UW ∧ Sys 동시 합격 = 합격. DW는 미고려(병기만)**.
기록 양식: **부록 9 §9-7 그대로** — DLC별 4표 (a: UW / b: DW / c: Sys 수명·ε / d: 해석시간, 빈수 열 포함).

### 4-1. (dt, k) 선정·검증 정책 스택 (260723 개정 — 승인)

**[선정]** (전 DLC, 스크리닝 맵 기반 · MASTA 불필요)
1. **연속 k + 중앙 타겟팅**: k를 그리드(0.05) 선형보간으로 연속화하고, 큰 dt 우선으로
   UW·Sys ∈ [0,3] 창 안에서 **ε_Sys가 목표 1.5%(창 중앙)에 최근접하는 k** 선택
   — min-k 선정이 Sys 하한 경계에 붙는 구조적 타이트함을 제거 (여유 ≥0.5%p 확보가 원칙)
2. **여유 <0.5%p(창 협소)면 dt 한 단계 축소** 후 재선정 — 보정 횟수 증가로는 창이 넓어지지 않으므로
   dt 축소가 구조적 해법
3. k 그리드 상한 3.0 (극저속 DLC6.4-a 계열의 k>1.5 수요 대응)
4. 적용 결과: **전 111 DLC ε_Sys 여유 ≥0.53%p** · dt=20 69개 유지 · 조합 배치 규모 9,150빈

**[검증·보정]** (참값 확보 DLC)
5. MASTA 실측 ε_UW·ε_Sys ∈ [0,3] 이면 확정
6. 불합격 시 **k 보정 최대 3회** (기존 1회→3회 완화, dt 보존 우선): 스크리닝 ε(k) 국소 기울기로
   `k′ = k + (1.5 − ε_실측)/기울기` → 해당 DLC만 재해석(회당 수 초~수십 초, 선형성으로 1회 수렴 기대)
7. 3회 실패 시에만 dt 축소
8. 전 DLC에서 |실측−예측| 기록 — 방법론 신뢰도 갱신

**[참값 방침]** (260723 확정)
9. **본격 배치 시 참값(dt=0.1 점별 MASTA)을 최우선으로 전 DLC 확보** — 이로써 ⑥의 보정 루프가
   전 DLC에 적용 가능해지고, 함대 합산은 참값 기반 정확값 사용

**표본 3 (DLC6.4-a-s3) 저속 κ클립·a_ISO 사전 검토** (MASTA 프로브 4점, 260723)

1. **κ 클립 실측**: 이론 κ(식 27+28) = 0.005~0.058 (전 점 유효범위 밖) → **MASTA는 전부 κ=0.1000으로 클립**
   — ISO 281 §9.3.4 하한("κ<0.1 계산 불가") 그대로. ν₁ 자체는 이론식과 0.1% 내 일치
2. **음수 rpm 처리**: MASTA는 ν₁에 **|n|** 사용 실측 확인 (rpm=−0.023 → ν₁=17,652 ≒ 이론 17,668)
3. **a_ISO = 0.1000 고정 (하중 무관)**: 저κ 구간 계수가 κ=0.1에서 κ항이 **정확히 0**이 되도록
   캘리브레이션됨 (1.5859−1.3993/0.1^0.054381 = −0.00006) → a_ISO = 0.1·1^(−9.185) = 0.1.
   의미: 심각한 경계윤활의 수명 페널티 바닥 = **기본수명의 10%**, 그 이하 외삽은 표준이 거부
4. **함의**: 스크리닝의 κ=0.1 클립 처리가 MASTA 내부 동작과 **구조적으로 동일** → κ클립 45개 DLC의
   예측 정합성 확보. 극저속 DLC는 수정수명 = 0.1×기본수명으로 단순화되어 κ 불확실성이 결과에 미포함

   범위 밖 — 본 DLC군의 "손상 미미" 결론은 피로 기준에 한정
7. 최적 k 갱신: 재스크리닝 후 본 표본 best = **(20, 1.15)** — 극저속·고CV 특성상 큰 k 필요 (본해석 대기)
