# 1. 개요

본 문서는 풍력터빈 드라이브트레인의 **메인샤프트**와 **메인베어링** 설계에 대한 설계 지침서 겸 보고서 양식이다. 대상은 로터 허브에서 전달되는 복합 변동 풍하중을 지지·전달하는 메인샤프트와, 메인샤프트를 지지하는 메인베어링(TRB×2)이다. 로터 허브에서 발생한 하중과 토크가 메인베어링에 지지된 메인샤프트를 통해 증속기(기어박스)로 전달되는 흐름을 다룬다.

- **대상 범위**: 메인샤프트 + 메인베어링
- **제외 범위**: 증속기(기어박스) 내부 설계 — 본 보고서에서는 인터페이스로만 다룸
- **설계 수명**: 20년급 (설계수명·등가피로 기준) [TBD — 프로젝트 사양 확정]
- **동력 전달 경로**: 로터 허브 → 메인샤프트(메인베어링 지지) → 증속기

> **[TBD] 필요 자료 (개요 확정용)**
> - 대상 터빈 정격출력·급 (MW class)
> - 드라이브트레인 형식 (3점 지지 / 4점 지지 / 모듈러 / 직결 등)
> - 프로젝트 요구 설계수명 및 가용률 목표

## 2.2 작동·경계 조건

하중·작동조건은 **IEC 61400-1**(하중 및 설계요구), **IEC 61400-4**(드라이브트레인 설계)를 기준으로 정의한다. 메인샤프트는 6자유도 하중, 메인베어링은 5자유도 하중을 대상으로 하며, 각각 **극한하중(Ultimate)** 과 **등가피로하중(Equivalent fatigue)** 으로 구분한다.

### 2.2.1 하중 정의

| 구분 | 성분 | 비고 |
| --- | --- | --- |
| 힘 (Force) | Fx, Fy, Fz | 축방향(Fx) + 반경방향(Fy, Fz) |
| 모멘트 (Moment) | Mx, My, Mz | 토크(Mx) + 굽힘(My, Mz) |
| 드라이브트레인 | 6-DOF (Fx, Fy, Fz, Mx, My, Mz) | 전체 성분 |
| 메인베어링 | 5-DOF (토크 Mx 제외) | 베어링은 순수 토크 미지지 |

# 4. 메인샤프트(드라이브트레인) 설계

## 4.1 구조

메인샤프트는 로터 허브와 증속기를 연결하며, 메인베어링(TRB×2)으로 지지되어 로터에서 전달되는 6자유도 복합 변동 풍하중을 받는다. 허브 측은 플랜지 결합, 증속기 측은 축 결합(수축끼움/커플링 등)으로 동력을 전달한다.

- **기능**: 허브 연결·지지, 증속기 연결·동력 전달, 메인베어링 하중 지지
- **주요 설계 과제**: 6-DOF 변동하중 하 피로수명 확보, 변형(처짐·경사) 억제, 베어링 좌면 응력집중·프레팅 관리, 나셀 패키징 내 경량화

# 5. 메인베어링 설계

## 5.1 구조

메인베어링은 **테이퍼 롤러 베어링(TRB) 2열** 구성으로, 메인샤프트를 지지하며 5자유도 복합 변동 풍하중(축·반경·굽힘모멘트)을 흡수한다. 배열은 정면조합(F2F) 또는 배면조합(B2B) 중 하중·강성·조립성을 고려하여 선정하고, 예압을 부여하여 강성과 접촉패턴을 확보한다.

- **기능**: 메인샤프트 지지, 5-DOF 복합 변동 풍하중 흡수
- **주요 설계 과제**: 변동하중 하 내부·표면기점 피로수명 확보, edge contact 회피(프로파일·리브), 그리스 윤활 유막 확보, 내륜 크립 방지, 예압 최적화
